## 변수에서 사람으로 시점을 옮긴다

!!! abstract ""
    변수 중심 접근이 '자기자비가 높을수록 ~하다'를 말한다면, 사람 중심 접근은 '자기자비의 **어떤 조합**을 가진 사람들이 있다'를 말합니다.

### 잠재프로파일분석 (LPA)

<div class="tri" markdown>

**1. 쉽게 말해** · 비슷한 응답 패턴끼리 사람들을 몇 개 유형으로 묶습니다. 예: 고몰입형 · 번아웃형 · 관망형.

**2. 논문·실무에선 이렇게 쓴다** · "자기자비의 6개 하위요인 프로파일에 따라 4개 잠재계층이 도출되었다(Entropy = .79)"

**3. 읽고 판단하는 법** · 계층 수는 **다섯 기준을 함께** 봅니다 — BIC 최저, Entropy ≥.80, LMR/BLRT 유의, 최소집단 5% 이상, **이론적 해석가능성**.

</div>

| 변수 중심 | 사람 중심 |
| --- | --- |
| 변인 간 관계를 봅니다.<br>모집단이 동질적이라고 가정.<br><br>회귀 · SEM · 다층<br><br>*무엇이 무엇에 영향을 주는가* | 사람들의 패턴을 봅니다.<br>모집단이 이질적 하위집단으로 구성.<br><br>LPA · LCA · 군집분석<br><br>*어떤 유형의 사람들이 있는가* |

### LPA의 세 가정

1. **국소독립성** — 계층 안에서는 지표들이 서로 독립
2. **정규성** — 계층 내 지표 분포가 정규 (LCA는 범주형이라 불필요)
3. **계층 수의 사전 미지** — 자료에서 결정

### 계층 수 결정 — 다섯 기준

| 기준 | 판정 | 주의 |
| --- | --- | --- |
| BIC · aBIC | 최저값 | 계층을 늘리면 계속 낮아질 수 있음 |
| Entropy | ≥ .80 | 분류 명확성 · 단독 근거 아님 |
| LMR-LRT · BLRT | p < .05 이면 k계층 채택 | k−1과의 비교 |
| 최소집단 비율 | ≥ 5% | 작은 집단은 재현되지 않음 |
| **이론적 해석가능성** | 계층에 이름을 붙일 수 있는가 | **가장 중요** |

!!! warning "통계만으로 정하지 않기"
    실습 데이터에서 k=6이 BIC는 더 낮지만 최소집단이 1.6%로 5% 규칙에 걸립니다. k=4가 BIC 급락 지점이면서 Entropy .79, 최소집단 7.6%로 방어 가능한 해입니다. **이런 상황이 실제로 자주 발생**합니다.

## LPA 이후 — BCH와 R3STEP

!!! abstract ""
    계층을 찾는 것은 시작입니다. **그 계층이 무엇 때문에 생겼고, 무엇으로 이어지는가**가 연구의 본론입니다.

### 분류 오류를 무시하면 안 되는 이유

LPA는 각 사람을 확률적으로 분류합니다. 어떤 사람은 1계층 소속 확률이 .95이고 어떤 사람은 .55입니다. 이 사람들을 똑같이 '1계층'으로 취급해 ANOVA를 돌리면 **분류 오차가 무시**되어 표준오차가 과소추정됩니다.

| 접근 | 하는 일 | 언제 | 도구 |
| --- | --- | --- | --- |
| **BCH** | 계층 → **결과변인** 비교, 분류오차 보정 | 프로파일별 성과·이직 차이 | Mplus AUXILIARY (BCH) |
| **R3STEP** | **예측변인** → 계층 소속 (다항로지스틱) | 무엇이 그 유형을 만드나 | Mplus AUXILIARY (R3STEP) |
| DU3STEP | 계층 → 결과변인, 분산 자유 추정 | 분산이 계층마다 다를 때 | Mplus AUXILIARY (DU3STEP) |
| 1-step | 계층과 외부변인을 동시 추정 | 이론이 확고할 때 | 계층 구조가 흔들릴 위험 |

### R3STEP 결과의 해석

다항로지스틱이므로 **참조계층 대비 승산비**로 읽습니다. "주도적 성격이 1점 높을수록 관망형(참조) 대비 자기수용형에 속할 승산이 1.84배였다"처럼 씁니다.

```r
# R에서의 근사 — tidyLPA + 사후확률 가중
fits <- tidyLPA::estimate_profiles(scale(ind), n_profiles = 1:6,
                                   variances = "equal", covariances = "zero")
tidyLPA::get_fit(fits)              # AIC BIC SABIC Entropy BLRT_p n_min

best <- estimate_profiles(scale(ind), n_profiles = 4)
d$class <- get_data(best)$Class
prop.table(table(d$class))          # 최소집단 5% 확인

# 계층 → 결과변인 (BCH의 R 근사)
aov1 <- aov(WE_TOT ~ factor(class), data = d)
effectsize::eta_squared(aov1); TukeyHSD(aov1)

# 예측변인 → 계층 (R3STEP의 R 근사)
nnet::multinom(factor(class) ~ PA_TOT + LS_TOT + tenure_yr, data = d)
```

!!! note "Mplus를 쓰는 편이 정확합니다"
    BCH와 R3STEP은 Mplus의 AUXILIARY 옵션으로 구현되어 있습니다. R의 tidyLPA로는 분류오차 보정이 완전하지 않으므로, 학위논문에서는 Mplus 사용과 그 옵션명을 명시하는 것이 정직합니다.

## 무엇이 먼저인가 — 자기회귀교차지연

T1의 자기 자신(자기회귀 AR)을 통제하고도 T1의 상대 변인이 T2를 예측한다면, 그 방향의 선행성을 주장할 수 있습니다. **양방향을 동시에 추정**해 두 계수를 비교해야 논증이 성립합니다.

!!! warning "측정동일성이 먼저"
    시점마다 같은 개념을 같은 방식으로 재고 있지 않다면 계수 비교 자체가 무의미합니다. 형태 → 요인부하 → 절편 순으로 제약하며 **ΔCFI ≤ .01, ΔRMSEA ≤ .015**를 확인합니다.

### RI-CLPM이 권장되는 이유

전통 CLPM은 개인 간 안정적 차이(어떤 사람은 늘 열의가 높다)와 개인 내 변동(이번 달엔 유독 낮다)을 섞어 버립니다. RI-CLPM은 무선절편으로 개인 간 성분을 먼저 빼내고 **개인 내 변동끼리** 교차지연을 추정합니다. 최근 심사에서 "RI-CLPM은 검토했는가"를 자주 묻습니다.

```r
f_cfg <- cfa(cfg, data = d, missing = "fiml")
f_met <- cfa(cfg, data = d, missing = "fiml", group.equal = "loadings")
semTools::compareFit(f_cfg, f_met)     # ΔCFI ≤ .01

f_clpm <- sem(clpm, data = d, missing = "fiml", estimator = "MLR")
f_eq   <- sem(clpm_equal, data = d, missing = "fiml", estimator = "MLR")
lavTestLRT(f_clpm, f_eq)     # 유의하면 두 방향의 크기가 다름
```

!!! note "실습 결과"
    이 데이터에서는 직무열의→이직의도(CL = −.20, p < .001)가 이직의도→직무열의(CL = −.04, n.s.)보다 강한 **비대칭** 구조입니다. 방향 논증이 성립하는 사례입니다.

## 언제 일어나는가 — 생존분석

'이직했는가'는 로지스틱이지만, '**언제** 이직했는가'는 생존분석입니다. 중도절단(아직 이직하지 않은 사람)을 버리지 않고 정보로 쓴다는 것이 결정적 장점입니다.

| 요소 | 뜻 | HRD 예 |
| --- | --- | --- |
| 사건 event | 관심 있는 사건 발생 | 이직 · 자격취득 · 중도탈락 |
| 시간 time | 관찰 시작부터 사건까지 | 입사 후 개월 |
| 중도절단 censoring | 관찰 종료까지 사건 미발생 | 조사 시점에 아직 재직 중 |

1. **Kaplan-Meier** 곡선 — 시각적 생존 확률
2. **Log-rank** — 집단 간 곡선 전체 비교
3. **Cox 비례위험모형** — 공변량 통제한 HR

!!! warning "비례위험 가정"
    Cox의 전제는 '집단 간 위험비가 시간에 무관하게 일정하다'입니다. Schoenfeld 잔차 검정에서 **p > .05**여야 하며, 위배 시 시간의존 공변량이나 층화 Cox로 전환합니다. 이 검정을 보고하지 않은 Cox 결과는 심사에서 지적됩니다.

```r
S  <- Surv(d$time_months, d$event)
km <- survfit(S ~ LS_grp, data = d)
survminer::ggsurvplot(km, pval = TRUE, risk.table = TRUE, conf.int = TRUE)
survdiff(S ~ LS_grp, data = d)                     # Log-rank
cox <- coxph(S ~ sex + age + SC_TOT + WE_TOT + TI_TOT, data = d)
broom::tidy(cox, exponentiate = TRUE, conf.int = TRUE)
cox.zph(cox)                                       # 비례위험 가정
```
