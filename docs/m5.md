## 세 가지 질문, 세 가지 도구

!!! abstract ""
    실무에서든 논문에서든 양적 분석의 90%는 이 세 질문 중 하나입니다.

| 질문 | 도구 | 핵심 지표 |
| --- | --- | --- |
| 함께 움직이나? | 상관 | r · ρ · τ — 단 **인과로 단정 금지** |
| 집단이 다른가? | 차이 검정 | t · F · χ² + 효과크기 d · η² |
| 무엇이 끌어올리나? | 회귀 | β · R² + 통제변인으로 순수 효과 |

이 세 도구는 모두 **일반선형모형(GLM)**의 변형입니다. t검정은 이분 더미 하나를 넣은 회귀이고, ANOVA는 더미 여러 개를 넣은 회귀입니다. 계보도의 정중앙에 GLM이 있는 이유입니다.

## 상관 — 함께 움직이나

### 상관계수 r

<div class="tri" markdown>

**1. 쉽게 말해** · 두 변인이 같은 방향으로 얼마나 함께 움직이는가. −1에서 +1 사이의 한 숫자로 요약합니다.

**2. 논문·실무에선 이렇게 쓴다** · 논문 **표 1(상관행렬)**에 항상 등장합니다. 대각선에는 α를 넣는 것이 관례입니다.

**3. 읽고 판단하는 법** · .10/.30/.50이 소·중·대. 다만 **N이 크면 r=.10도 유의**합니다 — 유의성이 아니라 크기를 해석하세요.

</div>

| 상황 | 지표 | 선택 이유 |
| --- | --- | --- |
| 연속 × 연속, 선형 | Pearson r | 기본형 |
| 서열척도 · 심한 편포 · 이상치 | Spearman ρ | 순위 기반 비모수 |
| 소표본 · 동점 많음 | Kendall τ | 일치쌍 기반, 소표본에 강건 |
| 이분 × 연속 | 점이연 r_pb | t검정과 동일한 정보 |
| 범주 × 범주 | Cramér's V | χ²의 효과크기 |
| 제3변인 통제 | 편상관 pr | 허위상관 제거 |

### 상관행렬을 읽는 법

- **방향**이 이론적 기대와 맞는가. 어긋난다면 **역문항 처리 오류**를 먼저 의심하세요.
- 구인 간 상관이 **.85를 넘으면** 판별타당도를 의심해야 합니다. 두 개념이 사실상 하나일 수 있습니다.
- 종속변인과 상관이 .10도 안 되는 예측변인은 회귀에서도 대개 유의하지 않습니다.

!!! warning "상관은 인과가 아니다"
    A와 B가 함께 움직이는 데는 네 가지 가능성이 있습니다. ① A→B ② B→A ③ 제3변인 C가 둘 다 유발 ④ 우연. 횡단자료는 이 넷을 구분하지 못합니다. "교육을 많이 받은 사람이 성과가 높다"에서 '교육이 성과를 높였다'로 건너뛰는 순간 논문은 무너집니다.

## 차이 검정 — 집단이 다른가

### t검정과 분산분석(F)

<div class="tri" markdown>

**1. 쉽게 말해** · 두 집단(t) 또는 세 집단 이상(F)의 평균이 우연 이상으로 다른지 판정합니다.

**2. 논문·실무에선 이렇게 쓴다** · 교육 이수·미이수, 부서별·세대별·직급별 비교. `t(431) = 2.14, p = .033`

**3. 읽고 판단하는 법** · 유의하면 **반드시 효과크기**(d, η²)를 붙이세요. 유의성은 표본 크기의 함수입니다.

</div>

| 상황 | 검정 | 전제 확인 | 사후 처리 |
| --- | --- | --- | --- |
| 두 독립집단 | 독립표본 t | Levene 등분산 → 위배 시 Welch | Cohen's d |
| 사전–사후 (같은 사람) | 대응표본 t | 차이점수 정규성 | d_z |
| 세 집단 이상 | 일원 ANOVA | 등분산 · 정규성 | 사후검정 + η² |
| 공변량 통제 | ANCOVA | 회귀선 평행성 | 부분 η² |
| 두 요인 이상 | 이원 ANOVA | 상호작용 우선 해석 | 단순주효과 분석 |
| 비모수 | Mann-Whitney · Kruskal-Wallis | — | 순위 기반 효과크기 |

### 사후검정 — 어느 것을 쓰나

| 방법 | 특징 | 쓸 때 |
| --- | --- | --- |
| Tukey HSD | 모든 쌍 비교, 균형설계에 최적 | 집단 크기가 비슷할 때 |
| Scheffé | 가장 보수적, 복합비교 가능 | 탐색적 비교가 많을 때 |
| Bonferroni | 단순하지만 과보수적 | 비교 수가 적을 때 |
| Games-Howell | 등분산 위배 시 | 집단 분산이 다를 때 |

!!! warning "유의함 ≠ 중요함"
    N=433에서는 평균 차이 0.1점도 유의할 수 있습니다. Cohen's d가 .15라면 통계적으로는 유의하지만 실질적으로는 무시할 수준입니다. **p와 효과크기를 반드시 함께** 보고하세요.

## 회귀 — 무엇이 결과를 끌어올리나

### 회귀분석

<div class="tri" markdown>

**1. 쉽게 말해** · 여러 후보 중 무엇이 결과를 얼마나 설명하는지, 다른 것들을 통제한 상태에서 따집니다.

**2. 논문·실무에선 이렇게 쓴다** · 논문 결과의 중심 표. `β = .34, p < .001, 95% CI [.24, .44]`

**3. 읽고 판단하는 법** · F가 유의한지 → adjusted R²가 얼마인지 → 어느 β가 큰지 → VIF가 10 미만인지 순으로 읽습니다.

</div>

| 비표준화 계수 B | 표준화 계수 β |
| --- | --- |
| X가 **1단위** 늘 때 Y의 실제 단위 변화.<br><br>· 실무·정책 함의를 말할 때<br>· 95% CI와 함께 보고<br><br>*단위가 다른 변인끼리 비교 불가* | X가 **1 SD** 늘 때 Y가 몇 SD 변하는지.<br><br>· 예측변인 간 상대 비교<br>· 척도가 다른 변인 비교<br><br>*실무 함의를 말하기엔 부적절* |

| 설명력 지표 | 뜻 | 주의 |
| --- | --- | --- |
| R² | 모형이 설명한 분산 비율 | 변인을 넣을수록 무조건 증가 |
| adjusted R² | 모수 수를 벌점으로 반영 | **반드시 병기** |
| sr² (준편상관²) | 한 변인의 고유 설명력 | ΔR²와 수치가 같음 |
| f² | 효과크기 | R²/(1−R²) · .02/.15/.35 |

### 진단 — 이것을 안 하면 계수를 믿을 수 없습니다

| 가정 | 진단 | 위배 시 |
| --- | --- | --- |
| 선형성 | 잔차 vs 적합값 산점도 | 다항항 · 변환 |
| 등분산성 | Breusch-Pagan | 로버스트 표준오차(HC3) |
| 잔차 정규성 | Q-Q plot · Shapiro | 부트스트랩 |
| 잔차 독립성 | Durbin-Watson 1.5~2.5 | 군집 표준오차 · 다층 |
| 다중공선성 | VIF < 10 (엄격 5) | 변인 통합 · 중심화 |
| 영향치 | Cook's D > 4/n · DFBETA | 제외 전후 결과 비교 보고 |

```r
m <- lm(JP_TOT ~ PA_TOT + SC_TOT + PC_TOT + CM_TOT + WE_TOT +
                  factor(sex) + age + tenure_yr, data = d)
summary(m); cbind(B = coef(m), confint(m))
car::vif(m); car::durbinWatsonTest(m)
performance::check_model(m)
```

## 위계적 회귀 — 순서가 곧 논증

### 위계적 회귀

<div class="tri" markdown>

**1. 쉽게 말해** · 변인을 한꺼번에 넣지 않고 **단계별로** 넣어, 각 단계가 설명력을 얼마나 더하는지 봅니다.

**2. 논문·실무에선 이렇게 쓴다** · "통제변인 투입 후에도 자기자비는 직무열의를 유의하게 설명하였다(ΔR² = .21, p < .001)"

**3. 읽고 판단하는 법** · **ΔR²와 F change**가 핵심 증거입니다. 개별 β보다 이쪽을 먼저 보세요.

</div>

### 투입 순서 — 이론이 정한다

1. **1단계** 인구·고용 통제변인 (성별·연령·근속·직급)
2. **2단계** 성향·개인차 변인 (주도적 성격 등)
3. **3단계** 핵심 독립변인 (자기자비·긍정심리자본)
4. **4단계** 조직·맥락 변인 (학습지원문화)
5. **5단계** 상호작용항 (조절효과 검증 시)

!!! warning "순서를 바꾸면 결론이 바뀝니다"
    3단계에 넣으면 유의했던 변인이 4단계에 넣으면 유의하지 않을 수 있습니다. 그래서 **순서의 이론적 근거**를 본문에 반드시 써야 합니다. '선행연구에서 통제한 순서를 따랐다'도 근거가 됩니다.

```r
s1 <- lm(WE_TOT ~ factor(sex) + age + tenure_yr + factor(rank), data = d)
s2 <- update(s1, . ~ . + PA_TOT)
s3 <- update(s2, . ~ . + SC_TOT + PC_TOT)
s4 <- update(s3, . ~ . + LS_TOT)
anova(s1, s2, s3, s4)     # F change — 핵심 증거
```

!!! note "실습 결과"
    이 데이터에서는 2단계 ΔR²=.086, 3단계 ΔR²=.214로 심리적 자원 변인이 가장 큰 증분을 보입니다. 4단계 조직맥락은 ΔR²=.011로 작지만 유의합니다 — 이런 결과를 어떻게 서술할지가 M9의 과제입니다.

## 종속변인이 이분형일 때 — 로지스틱

### 로지스틱 회귀

<div class="tri" markdown>

**1. 쉽게 말해** · 결과가 '예/아니오'일 때 쓰는 회귀. 확률이 아니라 **승산(odds)**의 로그를 예측합니다.

**2. 논문·실무에선 이렇게 쓴다** · 이직 여부, 자격증 취득 여부, 프로그램 수료 여부. `OR = 2.66, 95% CI [1.88, 3.76]`

**3. 읽고 판단하는 법** · OR의 **CI가 1을 포함하면** 유의하지 않습니다. Hosmer-Lemeshow는 **p > .05여야** 적합입니다.

</div>

### 왜 OLS가 안 되는가

- 예측값이 0 미만 또는 1 초과로 나옵니다.
- 잔차가 이항분포라 등분산·정규성 가정이 깨집니다.
- 확률과 예측변인의 관계는 직선이 아니라 S자입니다.

| 지표 | 기준 | 비고 |
| --- | --- | --- |
| OR + 95% CI | CI가 1을 포함하면 비유의 | 점추정치만 쓰지 말 것 |
| Wald 통계량 | (B/SE)² | 계수가 크면 과소검정 → LRT 병용 |
| Nagelkerke R² | — | 선형 R²와 다름을 각주로 명시 |
| Hosmer–Lemeshow | **p > .05**여야 적합 | 역방향 해석 주의 |
| AUC | ≥.70 수용 / .80 양호 / .90 우수 | 분류정확도·민감도·특이도 동반 |

!!! warning "OR ≠ 상대위험도(RR)"
    사건 발생률이 높으면(>10%) OR은 RR을 과장합니다. '2.66배 더 이직한다'가 아니라 '이직 **승산**이 2.66배'라고 써야 정확합니다.

```r
m1 <- glm(left_12m ~ sex + age + tenure_yr + n_prev_job +
            SC_TOT + PC_TOT + WE_TOT + TI_TOT, family = binomial, data = d)
exp(cbind(OR = coef(m1), confint(m1)))
ResourceSelection::hoslem.test(m1$y, fitted(m1), g = 10)
pROC::auc(pROC::roc(m1$y, fitted(m1)))
```
