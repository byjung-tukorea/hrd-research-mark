## 관계 그 자체를 자료로 삼는다

!!! abstract ""
    회귀는 '사람의 속성'을 자료로 씁니다. 네트워크 분석은 **사람들 사이의 관계**를 자료로 씁니다. 관측치가 개인이 아니라 **쌍(dyad)**입니다.

### 네트워크 분석

<div class="tri" markdown>

**1. 쉽게 말해** · 누가 누구와 연결되어 있는지를 점(노드)과 선(엣지)으로 그리고, 그 구조를 수치로 잽니다.

**2. 논문·실무에선 이렇게 쓴다** · "조언 네트워크에서 연결중심성이 높은 구성원일수록 혁신행동이 높았다"

**3. 읽고 판단하는 법** · 밀도·중심성·중심화를 함께 봅니다. 중심성은 **어떤 중심성인지**를 반드시 명시해야 합니다.

</div>

### 기본 어휘

| 용어 | 뜻 | HRD 해석 |
| --- | --- | --- |
| 노드 (node) | 점 — 개인·팀·조직 | 분석 단위 |
| 엣지 (edge/tie) | 선 — 관계 | 조언·협업·정보공유 |
| 방향성 | 화살표 유무 | '조언을 구한다'는 방향 있음 |
| 밀도 (density) | 가능한 연결 중 실제 연결 비율 | 네트워크의 촘촘함 |
| 연결중심성 (degree) | 직접 연결된 수 | 인기·활동성 |
| 매개중심성 (betweenness) | 최단경로를 지나는 빈도 | **정보 중개자** · 브로커 |
| 근접중심성 (closeness) | 다른 노드까지의 평균 거리 | 정보 접근성 |
| 아이겐벡터 | 연결된 상대의 중요도까지 반영 | 영향력 |
| 구조적 공백 | 연결되지 않은 집단 사이의 틈 | 중개 기회 |

### 데이터의 두 형식

| 인접행렬 (adjacency matrix) | 엣지리스트 (edge list) |
| --- | --- |
| N × N 정방행렬.<br>행 i, 열 j가 1이면 연결.<br><br>작은 네트워크에 편리<br>MR-QAP의 기본 형식 | from · to 두 열.<br>가중치 열 추가 가능.<br><br>큰 네트워크에 효율적<br>igraph의 기본 형식 |

!!! warning "네트워크 자료의 특수성"
    관측치가 서로 독립이 아닙니다. 일반 회귀의 표준오차가 완전히 틀리므로 **순열 검정(permutation)** 기반의 QAP 계열을 써야 합니다. 또한 **전수조사**가 원칙입니다 — 표본추출하면 네트워크 구조 자체가 왜곡됩니다.

## 네트워크에서 가설을 검정한다 — MR-QAP

"조언 네트워크가 협업 네트워크와 관련이 있는가", "같은 부서일수록 연결될 확률이 높은가" 같은 질문은 **관계행렬 간 회귀**입니다.

### 순열 검정의 논리

1. 실제 자료로 회귀계수를 계산합니다.
2. 종속 네트워크의 **행과 열을 무작위로 재배열**합니다 (노드 라벨 섞기).
3. 재배열된 자료로 계수를 다시 계산합니다.
4. 이를 수천 번 반복해 **영분포**를 만듭니다.
5. 실제 계수가 그 분포의 어디에 위치하는지로 p값을 구합니다.

```r
library(sna)
# 종속: 협업 네트워크, 독립: 조언 네트워크 + 동일부서 여부
y  <- collab_matrix
x  <- array(dim = c(2, n, n))
x[1,,] <- advice_matrix
x[2,,] <- same_dept_matrix

fit <- sna::netlm(y, x, reps = 5000, nullhyp = "qapspp")
summary(fit)
```

!!! warning "R² 해석 주의"
    QAP의 R²는 일반 회귀의 R²와 같은 의미로 읽으면 안 됩니다. 네트워크 자료는 관측치가 N²개라 R²가 낮게 나오는 것이 정상입니다. **계수의 방향과 유의성**에 초점을 맞추세요.

!!! quote "읽기 · 심화 경로"
    - `S2` 제4부 Ch.6 2차시 「MR-QAP — 네트워크에서 가설을 검정하는 법」
    - `S1` Ch.6 2차시 MR-QAP 분석

## 네트워크는 어떻게 진화하는가 — SAOM

!!! abstract ""
    종단 네트워크에서 가장 중요한 질문은 **선택인가 영향인가**입니다. 비슷한 사람끼리 연결된 것인가(selection), 연결되어서 비슷해진 것인가(influence)?

| 선택 효과 (selection) | 영향 효과 (influence) |
| --- | --- |
| 속성이 **관계 형성**을 예측.<br><br>비슷한 태도의 사람끼리<br>새로 연결된다.<br><br>*동질성 원리* | 관계가 **속성 변화**를 예측.<br><br>연결된 사람의 태도를<br>따라간다.<br><br>*전염·사회화* |

### 핵심 효과 키워드

| 효과 | 뜻 |
| --- | --- |
| density (outdegree) | 전반적 연결 경향 — 기본 효과 |
| reciprocity | 호혜성 — 내가 연결하면 상대도 연결 |
| transTrip | 전이적 삼각관계 — 친구의 친구가 친구가 됨 |
| egoX / altX | 보내는 쪽 / 받는 쪽의 속성 효과 |
| simX / sameX | 유사성 / 동일 범주 효과 → **선택** |
| avSim / totSim | 연결된 상대와의 평균 유사성 → **영향** |

### 분석 흐름과 점검

1. **수렴 점검** — 모든 효과의 t-ratio가 |t| < 0.10, 전체 최대 수렴비 < 0.25
2. **GOF** — 연결분포·삼각분포·측지거리 분포가 관찰치를 재현하는지
3. 수렴하지 않으면 `prevAns`로 이어받아 재추정
4. 효과를 너무 많이 넣으면 수렴하지 않습니다 — 이론적으로 필요한 것만

!!! note "최소 요건"
    시점이 **3개 이상**이어야 안정적입니다. 시점 간 변화량이 너무 크면(Jaccard 지수 < .30) 모형이 성립하지 않습니다.

## 텍스트의 잠재 구조

!!! abstract ""
    자유응답·인터뷰 전사·공고문처럼 **비정형 텍스트**에서 패턴을 찾는 방법입니다. HRD에서는 요구조사 자유응답, 직무기술서, 학습자 성찰일지 분석에 씁니다.

### 전처리 — 여기서 결과가 갈립니다

1. **형태소 분석** — 한국어는 KoNLPy(Python) 또는 KoNLP·RcppMeCab(R). 사용자 사전 등록이 필수적입니다.
2. **불용어 제거** — 도메인 불용어 목록을 직접 만들어야 합니다.
3. **동의어 통합** — '역량개발'·'역량 개발'·'competency development'
4. **품사 선택** — 대개 명사 중심. 동사·형용사 포함 여부를 밝히세요.

| 방법 | 원리 | 장점 | 한계 |
| --- | --- | --- | --- |
| 키워드 네트워크 | 동시출현 기반 단어 연결망 | 직관적 · 시각화 강력 | 빈도에 좌우됨 |
| LDA | 단어 분포의 혼합으로 토픽 추정 | 가장 오래된 표준 · 해석 관행 확립 | 토픽 수를 미리 정해야 함 · 짧은 글에 약함 |
| BERTopic | 임베딩 + 군집 + c-TF-IDF | 문맥 반영 · 짧은 글에 강함 | 재현성 확보에 주의 · 계산 비용 |
| STM | 공변량을 토픽 모델에 통합 | **연도·집단별 토픽 변화** 검증 가능 | 해석 난이도 높음 |

### 토픽 수 결정

- **일관성(coherence)** 지표 — 높을수록 좋음
- **혼란도(perplexity)** — 낮을수록 좋으나 해석가능성과 반비례하는 경향
- **해석가능성** — 결국 사람이 이름을 붙일 수 있어야 합니다
- 여러 개의 k를 돌려 놓고 **연구자와 전문가가 함께** 검토하는 것이 관례입니다

!!! warning "토픽 명명은 연구자의 책임"
    알고리즘은 단어 묶음을 줄 뿐입니다. 토픽 이름은 연구자가 붙이며, 그 근거(대표 단어 상위 10개 + 대표 문서 3건)를 반드시 제시해야 합니다. 명명 과정에 복수의 연구자가 참여하고 일치도를 보고하면 신뢰가 올라갑니다.
