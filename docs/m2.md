## 보이지 않는 것을 잰다는 것

!!! abstract ""
    '직무열의'는 자로 잴 수 없습니다. 우리가 재는 것은 언제나 **구인의 그림자**인 문항 응답입니다.

### 구인 · 조작적 정의 · 문항

1. **구인(construct)** — 이론적으로 정의된 추상 개념. 예: 직무열의
2. **조작적 정의** — 이 연구에서 그 개념을 어떻게 재는지의 선언. 예: '활력·헌신·몰두로 구성된 일에 대한 긍정적 충만 상태'
3. **문항** — 실제로 응답자가 읽는 문장. 예: '나는 일할 때 활력이 넘친다'

!!! warning "가장 흔한 붕괴 지점"
    조작적 정의는 A를 말하는데 척도는 B를 재는 경우입니다. '경력개발지원'을 정의해 놓고 '상사의 정서적 지지' 문항을 쓰면, 이후의 모든 계수는 다른 개념의 계수가 됩니다.

### 척도 4종 — 숫자가 '양'이냐 '이름표'냐

| 척도 | 예 | 가능한 통계 | 주의 |
| --- | --- | --- | --- |
| 명목 | 부서 · 직군 · 성별 | 빈도 · 최빈값 · χ² | **평균을 내면 안 되는 숫자** |
| 서열 | 직급 · 학력 · 리커트(논쟁) | 중앙값 · 순위상관 | 간격이 같다고 보장 못 함 |
| 등간 | 온도 · 표준점수 | 평균 · SD · 상관 · 회귀 | 절대 0이 없음 |
| 비율 | 급여 · 근속월수 · 연령 | 모든 통계 + 비율 해석 | 절대 0이 존재 |

!!! note "리커트는 서열인가 등간인가"
    엄밀히는 서열이지만, 5점 이상이고 문항을 합산해 척도점수로 쓸 때는 등간으로 취급하는 것이 관례입니다. 다만 **단일 문항**을 등간처럼 다루는 것은 방어하기 어렵습니다.

## 반영적 지표와 형성적 지표

| 반영적 Reflective | 형성적 Formative |
| --- | --- |
| 구인이 **원인**, 문항이 **결과**.<br>화살표: **구인 → 문항**<br><br>· 문항끼리 높은 상관을 가져야 정상<br>· 문항 하나를 빼도 개념이 유지됨<br>· α·AVE·CR로 평가<br><br>*대부분의 심리척도* | 문항이 **원인**, 구인이 **결과**.<br>화살표: **문항 → 구인**<br><br>· 문항 상관이 낮아도 무방<br>· 문항을 빼면 개념이 달라짐<br>· 가중치·VIF·외부타당도로 평가<br><br>*사회경제적 지위, 직무요구 총량* |

!!! warning "왜 중요한가"
    형성적 구인에 α나 AVE를 보고하면 **잘못된 지표**입니다. PLS-SEM을 쓰는 논문에서 가장 자주 지적되는 부분입니다. '직무요구'처럼 서로 다른 요구를 합산하는 개념은 형성적일 가능성이 높으니 반드시 확인하세요.

### 판별 질문 세 가지

1. 문항 하나를 빼면 **개념의 의미가 달라지는가**? → 그렇다면 형성적
2. 문항들이 서로 **대체 가능한가**? → 그렇다면 반영적
3. 구인이 변하면 **모든 문항이 함께** 변할 것으로 기대되는가? → 그렇다면 반영적

## 2차 요인구조 — HRD 척도의 기본형

!!! abstract ""
    HRD에서 다루는 개념 대부분은 **여러 하위요인을 거느린 상위 개념**입니다. 이 구조를 어떻게 다루느냐가 분석 전체를 좌우합니다.

### 실습 데이터의 측정모형

| 구인 | 하위요인 | 문항 | 구조 |
| --- | --- | --- | --- |
| 자기자비 | 자기친절 · 자기비난ᴿ · 보편적인간성 · 고립ᴿ · 마음챙김 · 과잉동일시ᴿ | 24 | 2차 (6하위) |
| 긍정심리자본 | 자기효능 · 희망 · 회복탄력 · 낙관 | 20 | 2차 (4하위) |
| 경력관리행동 | 경력탐색 · 네트워킹 · 자기제시 · 이동준비 | 16 | 2차 (4하위) |
| 직무열의 | 활력 · 헌신 · 몰두 | 12 | 2차 (3하위) |

### 2차 요인을 다루는 세 가지 방법

| 방법 | 하는 일 | 쓸 때 | 주의 |
| --- | --- | --- | --- |
| 총점 평균 | 전 문항 평균 하나 | 회귀·매개 등 관측변인 분석 | 하위요인 정보가 사라짐 |
| 하위요인 병렬 | 하위요인을 각각 독립변인으로 | 어떤 하위요인이 작동하는지 볼 때 | 다중공선성 급등 |
| 2차 요인모형 | CFA/SEM에서 위계 모형 추정 | 측정오차 보정이 필요할 때 | 1차 모형과 비교 필요 |

### 2차 요인모형이 정당한가 — Target coefficient

1차 요인모형의 χ²을 2차 요인모형의 χ²으로 나눈 값입니다. **.90 이상**이면 2차요인이 하위요인 간 상관을 충분히 설명한다고 봅니다.

```r
f1   <- cfa(cfa1, data = d, estimator = "MLR", missing = "fiml")   # 1차
f2nd <- cfa(cfa2, data = d, estimator = "MLR", missing = "fiml")   # 2차
lavTestLRT(f1, f2nd)
fitMeasures(f1,"chisq") / fitMeasures(f2nd,"chisq")   # Target coef ≥ .90
```

!!! warning "역문항이 섞인 2차요인"
    자기자비처럼 부적 하위요인(자기비난·고립·과잉동일시)이 포함된 척도는 그 하위요인들이 **별도의 방법요인**을 형성해 2요인 구조로 갈라지는 일이 흔합니다. 총점 사용 전에 반드시 요인구조를 확인하고, 갈라진다면 하위요인 분석을 택하는 편이 정직합니다.

!!! quote "읽기 · 심화 경로"
    - `S3` ③ 구조방정식모델 연구(박지원) pp. 57–60 「구조방정식모델이란 · 연구에서 사용되는 용어들」
    - `S2` 제3부 Ch.4 2차시 「측정모형 타당화(CFA)」

## 신뢰도 — α와 ω를 나란히

### Cronbach's α

<div class="tri" markdown>

**1. 쉽게 말해** · 같은 걸 여러 번 재도 일관된 값이 나오는가. 저울이 흔들리지 않나의 문제입니다.

**2. 논문·실무에선 이렇게 쓴다** · 모든 척도의 신뢰도 열에 등장합니다. `직무열의 척도의 신뢰도는 α = .89였다`

**3. 읽고 판단하는 법** · ≥ .70이면 양호, .60대는 탐색적 연구에서만 조건부 수용. 단 **α가 높다고 단일차원인 것은 아닙니다**.

</div>

| 지표 | 뜻 | 기준 | 전제 |
| --- | --- | --- | --- |
| Cronbach α | 문항들의 내적 일관성 | ≥ .70 | **타우등가**: 모든 문항 부하가 같다 |
| McDonald ω | 실제 요인부하 기반 합성신뢰도 | ≥ .70 | 타우등가 불필요 |
| 개념신뢰도 CR | SEM 맥락의 합성신뢰도 | ≥ .70 | 측정모형 추정 후 |
| 검사-재검사 | 시간에 걸친 안정성 | r ≥ .70 | 2~4주 간격 권장 |
| 평정자간 신뢰도 | 관찰자 간 일치 | ICC · κ ≥ .70 | 질적 코딩·역량평가 |

### α의 두 가지 함정

- **문항 수에 민감** — 문항이 많으면 문항 간 상관이 낮아도 α가 자동으로 올라갑니다. 20문항의 α=.90이 4문항의 α=.80보다 반드시 낫다고 할 수 없습니다.
- **단일차원성을 보장하지 않음** — 차원성은 요인분석이 판정합니다.

```r
psych::alpha(d[items], check.keys = FALSE)$total$raw_alpha
psych::omega(d[items], nfactors = 1, plot = FALSE)$omega.tot
psych::alpha(d[items])$alpha.drop      # 문항 제거 시 변화
```

!!! warning "문항 제거의 윤리"
    α를 올리려고 문항을 지우는 것은 흔하지만 위험합니다. 제거 근거는 통계치가 아니라 **내용타당도**여야 합니다. 실습 데이터에는 α ≈ .53인 '정서적 소진' 척도를 일부러 넣어 두었습니다 — 실제 자료에서도 이런 일이 생기며, 그때의 판단이 진짜 훈련입니다.

## 타당도 — 수렴과 판별

### 타당도

<div class="tri" markdown>

**1. 쉽게 말해** · 재려던 바로 그것을 진짜 재고 있는가. 체중계로 키를 재고 있지 않나의 문제입니다.

**2. 논문·실무에선 이렇게 쓴다** · 측정도구 절에서 요인부하량·AVE·CR·HTMT 표로 제시합니다.

**3. 읽고 판단하는 법** · λ ≥ .50, AVE ≥ .50, CR ≥ .70, HTMT < .85. 하나라도 미달하면 그 이유와 조치를 본문에 써야 합니다.

</div>

| 종류 | 묻는 것 | 지표 | 기준 |
| --- | --- | --- | --- |
| 내용타당도 | 문항이 개념 영역을 대표하는가 | 전문가 평정 CVR·CVI | 패널 수에 따른 임계값 |
| 구인타당도 | 의도한 요인구조가 나오는가 | EFA · CFA 적합도 | CFI ≥ .90, RMSEA ≤ .08 |
| 수렴타당도 | 같은 개념 문항끼리 모이는가 | λ · AVE · CR | λ ≥ .50~.70, AVE ≥ .50 |
| 판별타당도 | 다른 개념과 구별되는가 | √AVE · HTMT | √AVE > 상관, HTMT < .85 |
| 준거타당도 | 외부 준거를 예측하는가 | 준거와의 상관 | 이론적 기대 방향과 크기 |

### 판별타당도 — HTMT가 표준이 된 이유

Fornell–Larcker 기준(√AVE > 구인 간 상관)은 구인 간 상관이 .85를 넘어도 통과시켜 버리는 경우가 많다는 것이 시뮬레이션으로 밝혀졌습니다. HTMT는 그 상황을 잡아내기 때문에 최근 심사에서 선호됩니다. **둘 다 보고**하는 것이 가장 안전합니다.

!!! warning "AVE가 .50에 못 미칠 때"
    무조건 탈락은 아닙니다. CR ≥ .70이면 조건부 수용이 가능하다는 견해가 있습니다. 다만 **그 논거를 본문에 명시**해야 하며, 아무 말 없이 넘어가면 지적됩니다.

## EFA에서 CFA까지의 다리

!!! abstract ""
    EFA는 **구조를 발견**하고, CFA는 **구조를 확정**합니다. 순서와 역할이 다릅니다.

### 1단계 — EFA로 구조를 본다

- **요인추출** — 주축요인분해(PAF) 또는 최대우도(ML). 주성분분석(PCA)은 엄밀히는 요인분석이 아닙니다.
- **회전** — 요인 간 상관을 가정하면 사각회전(promax·oblimin), 아니면 직교회전(varimax). 사회과학에서는 대개 **사각회전**이 현실적입니다.
- **요인 수 결정** — 고유값 1 이상 규칙은 과대추정 경향이 있습니다. **평행분석(parallel analysis)**과 스크리 도표, 해석가능성을 함께 봅니다.
- **문항 제거** — 공통성 < .40, 요인부하 < .40, 교차부하 > .40 이면 검토 대상

### 2단계 — CFA로 구조를 확정한다

EFA와 **같은 표본으로 CFA를 하면 순환논증**입니다. 표본을 반으로 나누거나(split-half), 별도 표본을 확보하는 것이 원칙입니다. 학위논문에서 표본이 부족하면 그 한계를 명시하세요.

```r
# EFA — 평행분석으로 요인 수 결정
psych::fa.parallel(d[items], fm = "pa", fa = "fa")
efa <- psych::fa(d[items], nfactors = 4, rotate = "promax", fm = "pa")
print(efa$loadings, cutoff = .40)

# CFA — 구조 확정
f1 <- lavaan::cfa(model, data = d2, estimator = "MLR", missing = "fiml")
fit3(f1)
semTools::reliability(f1); semTools::AVE(f1)
```

!!! note "모형이 잘 안 맞을 때의 순서"
    ① 요인부하가 낮은 문항 확인 → ② 수정지수(MI) 확인하되 **이론적 근거가 있을 때만** 오차상관 허용 → ③ 그래도 안 되면 요인구조 자체를 재검토. 적합도를 맞추려고 오차상관을 다섯 개씩 추가하는 것은 자료에 모형을 맞추는 일입니다.

## 실습 2 — 측정모형 검증

```r
source("labs/R/00_setup.R")
d <- rd("12_cbsem_items.csv")

rev <- grep("R$", names(d), value = TRUE)   # 역문항 역채점
d[rev] <- 6 - d[rev]

sk(d[grep("^SC_", names(d))])               # 정규성 — ML 정당화

f1 <- cfa(cfa1, data = d, estimator = "MLR", missing = "fiml")
fit3(f1)
standardizedSolution(f1) |> filter(op == "=~", est.std < .50)

semTools::reliability(f1); semTools::AVE(f1); semTools::htmt(cfa1, data = d)

f2nd <- cfa(cfa2, data = d, estimator = "MLR", missing = "fiml")
fitMeasures(f1,"chisq") / fitMeasures(f2nd,"chisq")    # Target coefficient
```

### 확인할 것

- λ가 .50 미만인 문항이 있는가. 있다면 왜 그런가(내용·번안·역문항 위치).
- AVE ≥ .50, CR ≥ .70을 충족하는 하위요인은 몇 개인가.
- HTMT < .85를 넘는 구인 쌍이 있는가.
- 역문항으로 구성된 세 하위요인이 별도 방법요인을 형성하지는 않는가.
