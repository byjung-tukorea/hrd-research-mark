# M3 · 통계지표 계보도

> 지표를 목적으로 묶고 기법으로 잇는 지도

## 지표를 목적으로 묶는다

!!! abstract ""
    통계지표를 '어려운 순서'나 '배운 순서'가 아니라 **무엇을 하려는 도구인가**로 묶으면, 처음 보는 지표도 자리를 찾을 수 있습니다.

[**통계지표 계보도 →**](genealogy.md)

58개 지표를 5개 원으로 묶은 벤다이어그램. 배지를 누르면 뜻·수식·쓰는 순간·심사 포인트가 열립니다. LAYER 02에는 분석기법 14종이 각각 어떤 지표를 소집하는지 정리돼 있습니다.

### 다섯 개의 원

| 원 | 묻는 것 | 대표 지표 |
| --- | --- | --- |
| 관계·연관 | 얼마나 같이 움직이나 | r · ρ · τ · 편상관 · Cramér's V |
| 차이·비교 | 집단이 정말 다른가 | t · F · χ² · Cohen's d · η² |
| 예측·설명 | 무엇이 무엇을 만드나 | B · β · R² · ΔR² · OR · HR |
| 측정·구조 | 제대로 재고 있나 | α · ω · λ · AVE · CFI · RMSEA |
| 위계·다층 | 어느 층의 이야기인가 | ICC · τ₀₀ · τ₁₁ · γ · r_wg |

!!! note "사회과학 양적연구의 사고 흐름"
    **구성개념 → 측정 → 관계검증 → 해석·일반화**. 계보도의 다섯 원은 이 흐름의 어느 칸에 들어가는지로 위치가 정해집니다. 측정·구조 원은 2단계, 나머지 넷은 3단계에 해당합니다.

## 교집합에 있는 지표들

!!! abstract ""
    계보도의 핵심은 원이 아니라 **겹치는 자리**입니다. 두 목적을 동시에 수행하는 지표가 거기 있습니다.

| 교집합 | 지표 | 왜 두 곳에 걸치는가 |
| --- | --- | --- |
| 관계 ∩ 차이 | Cramér's V | 카이제곱(차이 검정)의 결과를 연관 강도로 환산 |
| 관계 ∩ 차이 | 점이연 상관 r_pb | 이분변인과 연속변인의 상관 = t검정과 같은 정보 |
| 관계 ∩ 예측 | sr² · ΔR² | 한 변인의 고유 설명력. 수치가 서로 같음 |
| 예측 ∩ 측정 | 간접효과 ab · 구조경로계수 | 측정오차를 보정한 예측 |
| 관계 ∩ 측정 | 요인부하량 λ · HTMT | 문항–요인 상관이자 타당도 증거 |
| 차이 ∩ 다층 | 우도비 검정 LRT | 모형 간 차이를 검정하되 위계 구조를 전제 |

### 정중앙 — GLM

상관·t검정·ANOVA·회귀는 서로 다른 기법이 아니라 **Y = Xβ + ε** 하나에서 갈라져 나온 변형입니다. t검정은 이분 더미 하나를 넣은 회귀이고, ANOVA는 더미 여러 개를 넣은 회귀입니다.

!!! note "방법론 장에 쓸 문장"
    "본 연구의 분석은 일반선형모형의 틀 안에서 수행되었다. 집단 간 비교는 더미코딩된 회귀로, 관계 검증은 다중회귀로 일관되게 접근하였으며, 종속변인이 이분형인 경우에만 로지스틱 연결함수를 적용하였다." — 이 한 문장이 방법론 이해도를 보여줍니다.

## 공통 판정단 — 어디에 있든 붙는 지표

!!! abstract ""
    어느 원에 있든 심사에서 반드시 확인받는 지표들입니다. 이것이 빠지면 나머지 숫자는 읽히지 않습니다.

| 지표 | 뜻 | 기준 | 자주 나오는 지적 |
| --- | --- | --- | --- |
| p | 영가설이 참일 때 관찰값 이상이 나올 확률 | .05 / .01 / .001 | p는 효과의 크기가 아닙니다 |
| 95% CI | 모수가 있을 법한 구간 | 0(OR·HR은 1) 포함 여부 | 점추정치만 보고하면 정밀도를 알 수 없음 |
| 검정력 1−β | 효과가 있을 때 잡아낼 확률 | ≥ .80 | 사후보다 사전 산출이 정당 |
| 효과크기 | 실질적 크기 | d .2/.5/.8 · f² .02/.15/.35 | p만 보고하면 반드시 지적 |
| VIF | 다중공선성 | < 10 (엄격 < 5) | 상호작용항 투입 시 급등 → 중심화 |
| Durbin-Watson | 잔차 독립성 | 1.5 ~ 2.5 | 종단·군집 자료에서 특히 중요 |
| 왜도·첨도 | 정규성 | |S|<2, |K|<7 | 위배 시 부트스트랩·로버스트 |
| 공통방법편의 | 동일응답자 인위상관 | 단일요인 < 50% | HRD 설문연구에서 가장 자주 요구 |
| AIC/BIC | 모형 선택 | 낮을수록 | 절대값이 아니라 상대 비교 |
| 결측 처리 | N과 처리 방식 | FIML 권장 | 밝히지 않으면 모든 수치의 신뢰가 흔들림 |

## 기법이 소집하는 지표 — LAYER 02

계보도의 두 번째 층은 분석기법 14종이 각각 어떤 지표를 필수로 요구하는지 보여줍니다. 아래는 요약이며, 인터랙티브 문서에서 각 지표를 눌러 확인할 수 있습니다.

| 기법 | 필수 보고 지표 | 판정 기준 |
| --- | --- | --- |
| 다중회귀 | B · β · R²/adjR² · F · VIF · DW | F 유의 · adjR² 병기 · VIF < 10 |
| 위계적회귀 | ΔR² · F change · f² | 단계별 ΔR²가 핵심 증거 |
| 매개 | a · b · c' · ab · Bootstrap CI | 5,000회 편향수정 CI가 0 미포함 |
| 조절 | 상호작용 β · ΔR² · 단순기울기 · J-N | 중심화 후 검정 |
| 조절된 매개 | **IMM** · 조건부 간접효과 | IMM의 CI가 0 미포함 |
| 직렬매개 | 특정 간접효과별 CI · 대비검정 | 경로 간 우열까지 진술 |
| 로지스틱 | OR(CI) · Wald · R²_N · H-L · AUC | OR CI가 1 미포함 · H-L은 p>.05 |
| LPA/LCA | AIC/BIC/aBIC · Entropy · LMR/BLRT | BIC 최저 + Entropy ≥.80 + 최소집단 5% |
| 생존분석 | HR(CI) · Log-rank · Schoenfeld | 비례위험 가정 검정 필수 |
| ARCL/CLPM | AR · CL · 측정동일성 · CFI/RMSEA | 동일성 확보 후 양방향 동시 추정 |
| HLM | ICC · τ₀₀ · τ₁₁ · γ · γ₁₁ · r_wg | ICC ≥ .05로 진입 정당화 |
| CB-SEM | λ · AVE · CR · HTMT · CFI · RMSEA · SRMR | 2단계 접근 · χ²/df ≤ 3 |
| PLS-SEM | 외부적재 · rhoC · HTMT · R² · f² · Q² | Q² > 0 · 부트스트랩 5,000회 |
| MSEM/종단SEM | 측정동일성 · ICC · 절편·기울기 무선효과 | 수준별 분산 분해 선행 |

## 실습 3 — 계보도로 내 논문 점검하기

!!! abstract ""
    내 논문(또는 최근 읽은 논문)의 결과표를 펴 놓고, 계보도를 체크리스트로 씁니다.

1. 내가 쓴 분석기법을 LAYER 02에서 찾습니다.
2. 그 카드의 '필수 보고 지표'와 내 결과표를 **한 줄씩 대조**합니다.
3. 빠진 지표에 표시합니다. 대개 효과크기·신뢰구간·가정 진단 셋 중 하나입니다.
4. '판정 기준'을 내 수치와 비교하고, 미달한 항목의 **방어 논거**를 한 줄로 씁니다.
5. 공통 판정단 10개를 훑고, 보고하지 않은 것이 있는지 확인합니다.

### 흔히 발견되는 누락 세 가지

- **효과크기 없음** — p값만 적고 d·f²·η²가 없는 경우. 가장 흔합니다.
- **가정 진단 없음** — 돌리긴 했으나 본문에 없는 경우.
- **결측 처리 미기재** — N이 표마다 다른데 왜 다른지 설명이 없는 경우.
