## 숫자를 문장으로

!!! abstract ""
    분석을 다 해 놓고 마지막에 무너지는 지점이 여기입니다. 숫자를 나열하는 것과 **결과를 진술하는 것**은 다릅니다.

### 한 문장의 구조

[무엇이] [무엇을] [어떻게] 했다 + (통계치, 유의성, 신뢰구간 또는 효과크기)

| 약한 문장 | 나은 문장 |
| --- | --- |
| "자기자비와 이직의도의 상관은 −.34로 나타났으며 이는 통계적으로 유의하였다(p<.001)."숫자를 옮겨 적었을 뿐, 무엇을 알게 됐는지가 없습니다. | "자기자비가 높은 재직자일수록 이직의도가 낮았다(r = −.34, p < .001). 이는 중간 크기의 관계로, 자기자비가 이직 억제 자원으로 기능할 가능성을 시사한다." |

### 결과 유형별 번역 템플릿

| 유형 | 템플릿 |
| --- | --- |
| 관계 | "A와 B는 정적 관계를 보였다(r = .42, p < .001). 단, 횡단자료이므로 인과는 아니며 추가 검증이 필요하다." |
| 차이 | "교육 이수자가 미이수자보다 성과가 높았다(t(431) = 2.14, p = .033, d = .21). 다만 효과크기는 작은 수준이었다." |
| 예측 | "직무열의는 이직의도를 유의하게 낮추는 요인이었다(β = −.34, p < .001, 95% CI [−.44, −.24])." |
| 매개 | "자기자비는 긍정심리자본을 매개로 직무열의를 높였다(ab = .33, 95% BCa CI [.24, .43])." |
| 조절 | "학습지원문화가 높을수록 그 효과가 강해졌다(ΔR² = .04, p < .001). J-N 분석 결과 학습지원문화 3.42 이상에서 효과가 유의하였다." |
| 다층 | "조직 간 분산이 14.4%였으며(ICC = .144), 교차수준 상호작용이 유의하였다(γ₁₁ = −.71, p = .009)." |
| **판단** | "따라서 자기자비 증진 프로그램을 학습지원문화가 갖춰진 조직부터 우선 도입할 것을 제안한다." |

!!! note "마지막 칸이 핵심"
    숫자 → 문장 → **액션**으로 이어지는 사슬이 연구의 최종 산출물입니다. 실무 보고서든 학위논문이든, '그래서 무엇을 할 것인가'가 없으면 결과는 소비되지 않습니다.

## APA 표기와 결과표

| 대상 | 표기 | 비고 |
| --- | --- | --- |
| 통계 기호 | *이탤릭* — *M, SD, r, t, F, p, R²* | 그리스 문자(β, χ², η²)는 정체 |
| 소수점 | 0 생략: *r* = .34, *p* = .003 | 1을 넘을 수 있는 값은 유지: *M* = 3.15 |
| p값 | *p* < .001 / *p* = .023 | p = .000 은 쓰지 않습니다 |
| 자유도 | *t*(431) = 2.14, *F*(3, 429) = 8.62 | 괄호 안 |
| 신뢰구간 | 95% CI [.24, .44] | 대괄호 |
| 표 제목 | 표 위, 이탤릭 없이 | APA 7판은 굵게 |
| 그림 제목 | 그림 위 (6판은 아래) | 7판에서 바뀌었습니다 |

### 논문 결과 장의 표 순서

1. **표 1** 표본의 인구통계학적 특성
2. **표 2** 주요 변인의 기술통계와 상관행렬 (대각선에 α)
3. **표 3** 측정모형 검증 결과 (λ, AVE, CR) — SEM인 경우
4. **표 4** 주 분석 결과 (회귀표 · 경로계수표 · 다층 결과표)
5. **표 5** 간접효과·조건부효과 검정 결과
6. **그림** 연구모형 + 유의한 경로만 표시한 결과 모형

### 하지 말아야 할 진술

- 횡단자료로 "영향을 미쳤다", "효과가 있었다" → '관련이 있었다', '예측하였다'
- "유의한 차이가 없으므로 두 집단은 같다" → 영가설 채택 불가. '차이를 확인하지 못하였다'
- "매우 유의하였다" → p는 정도가 없습니다
- 가설과 반대 결과를 사후에 합리화 → 예상과 달랐다는 것을 먼저 쓰고 해석은 그다음

## 논의와 한계

### 논의 장의 구조

1. **요약** — 연구문제별 주요 결과 (숫자 반복 금지)
2. **해석** — 왜 이런 결과가 나왔는가, 이론과 어떻게 연결되는가
3. **선행연구 대조** — 일치하는 부분과 **다른 부분**, 특히 다른 이유
4. **이론적 시사점** — 기존 이론에 무엇을 더했는가
5. **실천적 시사점** — HRD 담당자가 무엇을 다르게 할 수 있는가
6. **한계와 후속연구**

| 약한 한계 진술 | 나은 한계 진술 |
| --- | --- |
| "표본이 특정 산업에 한정되어 일반화에 제약이 있다" | "제조업 재직자가 65%를 차지해 서비스업 맥락에서는 학습지원문화의 조절효과가 다르게 나타날 수 있다. 업종별 다집단 분석이 후속 과제다" |
| "횡단연구라 인과관계를 알 수 없다" | "X와 M을 동시 측정하여 매개의 시간적 선행을 확인하지 못했다. 향후 4주 간격 시차설계로 a 경로의 방향을 검증할 필요가 있다" |
| "자기보고식 측정의 한계가 있다" | "직무성과를 자기보고로 측정해 공통방법편의 가능성이 남는다. Harman 검정과 잠재방법요인으로 통제를 시도했으나, 상사 평정 자료 확보가 근본적 해법이다" |

!!! note "한계는 방어가 아니라 설계"
    한계 절은 심사자가 지적할 것을 **먼저 정확히 짚어** 두는 자리입니다. 막연하게 쓰면 오히려 '알면서 안 했다'로 읽힙니다. 구체적으로 쓰고, 후속 연구 방향까지 붙이면 기여가 됩니다.
