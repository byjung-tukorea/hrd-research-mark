## 도구로서의 AI, 한계로서의 환각

!!! abstract ""
    AI는 연구 속도를 바꾸지만 **책임은 바꾸지 않습니다**. 인용 하나가 틀리면 그 책임은 연구자에게 있습니다.

### 환각의 실체

언어모델은 **그럴듯한 다음 단어**를 예측합니다. 실제로 존재하는 논문인지 확인하는 기능이 아닙니다. 존재하지 않는 저자·연도·제목·DOI를 완벽하게 그럴듯한 형식으로 만들어 냅니다. 형식이 정확할수록 오히려 위험합니다.

### 환각 차단의 네 원칙

1. **원문 확인 없는 인용 금지** — AI가 준 서지사항은 **반드시** DOI나 학술DB에서 검증합니다.
2. **요약은 원문 첨부 후에만** — 논문 PDF를 넣고 요약시키면 환각이 크게 줄어듭니다. 제목만 주고 요약을 요청하면 지어냅니다.
3. **숫자는 직접 계산** — AI가 계산한 통계치를 그대로 쓰지 마세요. 코드로 재현합니다.
4. **기록을 남긴다** — 어떤 모델로 무엇을 했는지 로그를 남기면 나중에 소명이 됩니다.

| 단계 | AI 활용 가능 | 반드시 사람이 |
| --- | --- | --- |
| 문헌 탐색 | 검색어 확장 · 관련 분야 제안 | 실제 논문 확보와 정독 |
| 문헌 요약 | **원문 첨부 후** 구조화 요약 | 핵심 주장의 정확성 판단 |
| 연구설계 | 대안 설계 브레인스토밍 | 이론적 정당화 |
| 코드 작성 | 초안 생성 · 디버깅 | 결과의 타당성 검증 |
| 결과 해석 | 해석 관점 제안 | 최종 해석과 서술 |
| 영문 교정 | 문법·표현 다듬기 | 내용의 정확성 |
| **인용** | **금지** — 검증 없이 절대 사용 불가 | 전수 검증 |

!!! warning "학술지 정책 확인"
    대부분의 학술지가 AI 사용 시 **방법 절에 명시**할 것을 요구하며, AI를 저자로 등재하는 것을 금지합니다. 투고 전 해당 학술지의 최신 정책을 반드시 확인하세요.

## AI로 코드와 해석을 보조하기

### 코드 생성 프롬프트의 표준 형식

막연하게 요청하면 막연한 코드가 나옵니다. 다음 네 가지를 명시하세요.

1. **데이터 구조** — 변수명, 척도, N, 결측 여부
2. **분석 목적** — 무엇을 검정하려는가
3. **환경** — R/Python, 패키지 버전
4. **출력 형태** — 표? 그림? APA 형식?

```r
# 좋은 프롬프트 예
"R lavaan으로 2차 요인 CFA를 하려고 합니다.

 데이터: 433행. 자기자비 24문항(SC_SK_01~04, SC_SJ_01R~04R, ...),
        6개 하위요인, 5점 리커트, 문항 결측 0.4%, 역문항은 R로 끝남.
 목적:   1차 모형과 2차 모형 적합도 비교 + Target coefficient 산출.
 출력:   적합도 지수 표와 표준화 부하량, 주석은 한국어로."
```

### AI 활용 시 흔한 실수

- **결과를 그대로 붙여넣기** — 변수명이 다른데 코드가 돌아가면 다른 걸 분석한 것입니다.
- **패키지 버전 불일치** — 없어진 함수, 바뀐 인자명. 항상 실행해 보세요.
- **통계적 판단을 위임** — "이 결과 어떻게 해석해?"에 대한 답을 그대로 쓰면 안 됩니다.
- **데이터 업로드** — 개인정보가 포함된 원자료를 외부 서비스에 올리면 IRB 위반이 될 수 있습니다.

!!! warning "데이터 보안"
    응답자 식별 가능 정보(이름·사번·이메일·소속)가 포함된 파일은 **절대** 외부 AI 서비스에 올리지 마세요. 필요하다면 변수명과 구조만 텍스트로 설명하거나, 완전 비식별화된 소표본을 만들어 쓰세요.

## 누수 없는 4년 — 자료관리 워크플로우

!!! abstract ""
    박사과정 4년 동안 파일은 수천 개가 됩니다. 3년차에 "그 분석 어느 파일이었지"를 겪지 않으려면 처음부터 규칙이 필요합니다.

### 권장 폴더 구조

```
dissertation/
├─ 01_literature/       문헌 PDF (Zotero 연동)
├─ 02_instrument/       측정도구 · 설문지 · IRB 문서
├─ 03_data/
│   ├─ raw/             원자료 — 절대 수정 금지 (읽기 전용)
│   ├─ processed/       정제본 (스크립트로 생성)
│   └─ codebook.xlsx
├─ 04_analysis/
│   ├─ scripts/         01_clean.R, 02_cfa.R, 03_sem.R ...
│   ├─ output/          표·그림 (스크립트가 생성)
│   └─ log/             분석 로그
├─ 05_manuscript/       초고 (버전별)
```
