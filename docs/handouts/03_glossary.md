## 자주 틀리는 표기

| 잘못 | 바름 | 이유 |
|---|---|---|
| p = .000 | p < .001 | p는 0이 될 수 없습니다 |
| r = 0.34 | r = .34 | 1을 넘을 수 없는 값은 앞의 0 생략 |
| M = .15 (평균) | M = 3.15 | 1을 넘을 수 있는 값은 0 유지 |
| 매우 유의한 | 유의한 | p에는 정도가 없습니다 |
| 유의한 차이가 없어 동일하다 | 차이를 확인하지 못하였다 | 영가설 채택 불가 |
| (횡단) 영향을 미쳤다 | 관련이 있었다 / 예측하였다 | 인과 주장 불가 |
| 오즈비가 2배 더 발생 | 발생 승산이 2배 | OR ≠ 발생 확률의 배수 |
| 신뢰도가 타당하다 | 신뢰도가 확보되었다 | 신뢰도와 타당도는 다른 개념 |
| 변수 | 변인 | 교육학·HRD 관례 (통계학은 변수) |
| 요인분석 결과 신뢰도가 | 요인분석 결과 타당도가 | 요인분석은 타당도 증거 |
