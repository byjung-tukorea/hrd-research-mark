# 기법별 보고 체크리스트
### 결과표를 쓸 때마다 옆에 두고 한 줄씩 대조

---

## 0. 모든 분석에 공통

- [ ] 수집 N → 제외 N과 사유 → 최종 분석 N
- [ ] 결측률과 처리 방식 (목록별 삭제 / FIML / 다중대체)
- [ ] 기술통계: M, SD, 최소·최대, 왜도, 첨도
- [ ] 정규성 판단 근거 (|왜도| < 2, |첨도| < 7)
- [ ] 신뢰도 α (가능하면 ω 병기)
- [ ] 상관행렬 (APA 형식, 대각선에 α)
- [ ] 공통방법편의 점검 결과
- [ ] p값과 함께 **효과크기**
- [ ] 주요 추정치의 **95% 신뢰구간**
- [ ] 사용 소프트웨어와 버전, 패키지명

---

## 01 · 다중회귀

- [ ] F, df, p (모형 전체 유의성)
- [ ] R², **adjusted R²**
- [ ] 비표준화 B와 표준오차, 95% CI
- [ ] 표준화 β
- [ ] VIF (< 10, 엄격 < 5)
- [ ] Durbin-Watson (1.5~2.5)
- [ ] 잔차 정규성·등분산 진단
- [ ] 영향치 점검 (Cook's D)
- [ ] 효과크기 f²

## 02 · 위계적 회귀

- [ ] 단계별 R², adjR², **ΔR²**, F change, df
- [ ] 투입 순서의 **이론적 근거**를 본문에 서술
- [ ] 각 단계 β를 세로 배열한 표
- [ ] ΔR²와 sr²는 같은 값이므로 하나만

## 03 · 매개

- [ ] a, b, c, c' 경로계수와 유의성
- [ ] **간접효과 ab**와 부트스트랩 편향수정 95% CI
- [ ] 부트스트랩 횟수 (5,000회 권장)
- [ ] 총효과와 매개비율
- [ ] '완전/부분매개' 이분법 대신 크기와 CI로 서술
- [ ] 횡단자료라면 시간적 선행성 한계 명시

## 04 · 조절

- [ ] 평균중심화 여부와 이유
- [ ] 상호작용항 β, p
- [ ] **ΔR²**와 F change
- [ ] VIF (중심화 후 재확인)
- [ ] 단순기울기 (±1SD) 계수와 유의성
- [ ] **상호작용 도표** (필수)
- [ ] 가능하면 Johnson-Neyman 유의영역

## 05 · 조절된 매개 / 매개된 조절 / 3원 상호작용

- [ ] **조절된 매개 지수(IMM)**와 CI ← 이것이 결론
- [ ] 조절변인 수준별 조건부 간접효과와 CI
- [ ] 3원 상호작용은 하위 2원항을 모두 투입했는지
- [ ] PROCESS 사용 시 **모형 번호** 명시
- [ ] 도표 (2×2 또는 조건부 효과 그래프)

## 06 · 직렬(이중) 매개

- [ ] 특정 간접효과 각각의 CI
- [ ] 총간접효과 CI
- [ ] 경로 간 **대비(contrast) 검정**
- [ ] 매개변인 투입 순서의 이론적 근거

## 07 · 로지스틱 회귀

- [ ] OR = e^B 와 **95% CI** (1 포함 여부)
- [ ] Wald 통계량 또는 z
- [ ] 우도비 검정 (모형 전체)
- [ ] Nagelkerke R² (선형 R²와 다름을 각주)
- [ ] **Hosmer-Lemeshow** (p > .05여야 적합)
- [ ] AUC와 분류정확도·민감도·특이도
- [ ] OR과 상대위험도(RR)를 구분해 서술

## 08 · 잠재프로파일 / 잠재계층

- [ ] 계층 수별 AIC, BIC, aBIC
- [ ] **Entropy** (≥ .80)
- [ ] LMR-LRT, BLRT의 p값
- [ ] **최소집단 비율** (≥ 5%)
- [ ] 최종 해 선택의 **이론적 해석가능성** 서술
- [ ] 계층별 지표변인 프로파일 표와 그래프
- [ ] 계층 명명의 근거
- [ ] 외부변인과의 관계 (분류 오차 처리 방식 명시)

## 09 · 생존분석

- [ ] 사건 정의, 관찰 시작·종료 시점
- [ ] **중도절단 비율**
- [ ] Kaplan-Meier 곡선 (risk table 포함)
- [ ] Log-rank 검정
- [ ] HR과 95% CI
- [ ] **비례위험 가정 검정** (Schoenfeld)
- [ ] 위배 시 대응 (시간의존 공변량 / 층화 Cox)
- [ ] HR과 OR을 구분해 서술

## 10 · 자기회귀교차지연

- [ ] 시점 간 간격과 그 근거
- [ ] **측정동일성** 검증 (형태→부하→절편, ΔCFI ≤ .01)
- [ ] 자기회귀계수(AR) 양방향
- [ ] 교차지연계수(CL) **양방향 모두**
- [ ] 두 방향 계수 차이 검정
- [ ] 적합도 세트
- [ ] 패널 이탈 분석 (attrition analysis)
- [ ] RI-CLPM 검토 여부

## 11 · 다층분석 (HLM)

- [ ] **ICC(1)** 과 진입 정당화
- [ ] 조직 수, 조직당 평균·최소 사례수
- [ ] 합산 시 r_wg, ICC(1), ICC(2)
- [ ] **중심화 방식**(집단평균/전체평균)과 이유
- [ ] 단계별 모형: 무조건 → 무선계수 → 절편 → 절편·기울기
- [ ] τ₀₀, τ₁₁과 유의성
- [ ] γ 계수와 표준오차, 신뢰구간
- [ ] 교차수준 상호작용 γ₁₁과 단순기울기 도표
- [ ] REML(무선효과) / ML(고정효과) 구분
- [ ] 설명분산 (Pseudo-R² 또는 Nakagawa R²)

## 12 · CB-SEM

- [ ] 측정모형 적합도 (χ²/df, CFI, TLI, RMSEA+90%CI, SRMR)
- [ ] 표준화 λ (≥ .50)
- [ ] AVE (≥ .50), CR (≥ .70)
- [ ] 판별타당도: √AVE vs 상관, **HTMT** (< .85)
- [ ] 2차 요인모형이면 Target coefficient (≥ .90)
- [ ] 구조모형 적합도
- [ ] 경로계수와 CR(≥1.96) 또는 부트스트랩 CI
- [ ] 내생변인 R²
- [ ] 수정지수 사용 시 **이론적 근거** 서술
- [ ] 추정법(ML/MLR)과 선택 이유

## 13 · PLS-SEM

- [ ] PLS를 선택한 이유 (예측 목적 / 형성적 구인 / 모형 복잡도)
- [ ] 외부적재 (≥ .70)
- [ ] rhoA, rhoC, AVE
- [ ] HTMT (< .85)
- [ ] 내부 VIF (< 5)
- [ ] 경로계수 + **부트스트랩 5,000회** t 또는 CI
- [ ] R², f²
- [ ] **Q²** (> 0), 가능하면 PLSpredict
- [ ] SRMR

## 14 · MSEM / 종단 SEM / DSEM

- [ ] 수준별 ICC
- [ ] 측정동일성
- [ ] 성장모형 절편·기울기의 평균과 분산
- [ ] 시간 코딩 방식(0,1,2 등)과 그 의미
- [ ] 조건부 성장모형의 예측변인 효과
- [ ] 결측 처리(FIML)와 MAR 가정의 타당성 논의
- [ ] AIC/BIC는 상대 비교로만 사용
- [ ] DSEM 사용 시 소프트웨어(Mplus/brms) 명시

---

## 부록 · 자주 빠뜨리는 세 가지

1. **효과크기** — p값만 있고 d·f²·η²·R²가 없음
2. **가정 진단** — 돌리긴 했는데 본문에 없음
3. **결측 처리** — 표마다 N이 다른데 설명이 없음
