## 1. 기호 사전

### 기술통계

| 기호 | 한 줄 풀이 | 기준·주의 |
|---|---|---|
| *M* | 평균 | 왜도가 크면 대표하지 못함 |
| *SD* | 표준편차 — 흩어진 정도 | 평균의 절반 넘으면 넓은 분포 |
| *Mdn* | 중앙값 | 왜도 클 때 M과 병기 |
| *N* / *n* | 전체 / 하위집단 표본 | 표마다 다르면 결측 처리 명시 |
| Skew | 왜도 | \|왜도\| < 2 |
| Kurt | 첨도 | \|첨도\| < 7 |

### 관계·검정

| 기호 | 한 줄 풀이 | 기준선 |
|---|---|---|
| *r* | 상관계수 | −1~+1 · .10/.30/.50 소·중·대 · **인과 아님** |
| ρ / τ | Spearman / Kendall | 순위 기반 비모수 |
| β | 표준화 회귀계수 | 변인 간 상대 비교용 |
| *B* | 비표준화 계수 | 실무·정책 함의용 |
| *R*² | 설명력 | adjusted R² 병기 |
| Δ*R*² | 증분 설명력 | 위계적 회귀의 핵심 증거 |
| *p* | 유의확률 | < .05 · .01 · .001 · **크기 아님** |
| *t* / *F* | 차이 검정값 | 자유도 병기 |
| χ² | 빈도 괴리 · 적합도 | 표본 크기에 민감 |
| OR | 승산비 | 기준 1 · CI가 1 포함하면 비유의 |
| HR | 위험비 | 기준 1 · 시간 정보 포함 |

### 측정·모형

| 기호 | 한 줄 풀이 | 기준선 |
|---|---|---|
| α | Cronbach 신뢰도 | ≥ .70 (탐색 .60) |
| ω | McDonald 신뢰도 | ≥ .70 · α의 가정 완화 |
| λ | 요인부하량 | ≥ .50 (양호 .70) |
| AVE | 평균분산추출 | ≥ .50 |
| CR | 개념신뢰도 | ≥ .70 |
| HTMT | 판별타당도 | < .85 |
| χ²/df | 적합도 | ≤ 3 (양호 ≤ 2) |
| CFI / TLI | 상대적합 | ≥ .90 (양호 ≥ .95) |
| RMSEA | 절대적합 | ≤ .08 (양호 ≤ .06) · 90% CI 상한까지 |
| SRMR | 잔차 기반 | ≤ .08 |
| Q² | 예측적합도 (PLS) | > 0 |

### 효과크기

| 기호 | 쓰는 곳 | 소 / 중 / 대 |
|---|---|---|
| *d* | t검정 | .2 / .5 / .8 |
| η² | ANOVA | .01 / .06 / .14 |
| *f*² | 회귀 · PLS | .02 / .15 / .35 |
| *V* | 교차분석 | 자유도에 따라 다름 |
| *r* | 상관 | .10 / .30 / .50 |

### 다층·유형

| 기호 | 한 줄 풀이 | 기준선 |
|---|---|---|
| ICC(1) | 집단 소속의 설명력 | ≥ .05~.10 → 다층 정당화 |
| ICC(2) | 집단 평균의 신뢰도 | ≥ .70 → 합산 정당화 |
| r_wg | 집단 내 합의도 | ≥ .70 |
| τ₀₀ | 절편 분산 | 유의하게 0이 아닌가 |
| τ₁₁ | 기울기 분산 | 유의하면 조절변인 탐색 |
| γ | 고정효과 계수 | 중심화 방식에 따라 의미 변화 |
| γ₁₁ | 교차수준 상호작용 | 유의하면 단순기울기 도표 필수 |
| Entropy | LPA 분류 명확성 | ≥ .80 |

**별표** \* *p* < .05 · \*\* *p* < .01 · \*\*\* *p* < .001

## 3. 결과 → 문장 → 판단

| 유형 | 템플릿 |
|---|---|
| 관계 | "A와 B는 정적 관계를 보였다(*r* = .42, *p* < .001). 단, 횡단자료이므로 인과는 아니다." |
| 차이 | "이수자가 미이수자보다 높았다(*t*(431) = 2.14, *p* = .033, *d* = .21). 효과크기는 작은 수준이었다." |
| 예측 | "직무열의는 이직의도를 유의하게 낮추었다(β = −.34, *p* < .001, 95% CI [−.44, −.24])." |
| 매개 | "긍정심리자본을 매개로 직무열의를 높였다(ab = .33, 95% BCa CI [.24, .43])." |
| 조절 | "학습지원문화가 높을수록 효과가 강해졌다(Δ*R*² = .04, *p* < .001)." |
| 다층 | "조직 간 분산이 14.4%였으며(ICC = .144), 교차수준 상호작용이 유의하였다(γ₁₁ = −.71, *p* = .009)." |
| **판단** | "따라서 ○○ 프로그램을 △△ 조건이 갖춰진 조직부터 우선 도입할 것을 제안한다." |

## 5. 분석 전 최종 점검

- [ ] 수집 N → 제외 N과 사유 → 최종 N을 적었는가
- [ ] 불성실 응답 기준을 **복수**로 적용했는가
- [ ] 역문항을 역채점했는가 (이중 역채점 아닌가)
- [ ] 결측 기제를 판단하고 처리 방식을 정했는가
- [ ] 왜도·첨도가 기준 안인가
- [ ] 신뢰도(α, 가능하면 ω)를 확보했는가
- [ ] 공통방법편의를 점검했는가
- [ ] 다중공선성(VIF)을 확인했는가
- [ ] **효과크기**를 보고할 준비가 되었는가
- [ ] **신뢰구간**을 보고할 준비가 되었는가
