## 자료의 품질이 결론의 상한선

!!! abstract ""
    아무리 정교한 모형도 자료의 품질을 넘어설 수 없습니다. 이 시간은 **분석 전에 끝나야 하는 일**을 다룹니다.

### 정제 파이프라인

1. 수집 원자료 백업 (절대 덮어쓰지 않음)
2. 불성실 응답 탐지 → 제외 기준 확정 → 제외
3. 역문항 역채점
4. 결측 진단 → 결측 기제 판단 → 처리 방식 결정
5. 이상치 탐지 → 처리(유지/윈저화/제외)와 근거
6. 기술통계 · 정규성 · 신뢰도
7. 공통방법편의 점검
8. → 여기까지 끝나야 가설검증 시작

!!! warning "논문에 반드시 남길 것"
    수집 N → 제외 N과 사유 → 최종 분석 N. 이 세 숫자가 없으면 표본의 대표성을 판단할 수 없습니다. 본 실습 데이터는 468명 수집 → 35명 제외(7.5%) → 433명입니다.

## 불성실 응답 — 어떻게 잡아내는가

### 불성실 응답

<div class="tri" markdown>

**1. 쉽게 말해** · 설문을 성의 없이 채운 사람들. 다 같은 번호를 찍거나, 지그재그로 찍거나, 5분 만에 100문항을 끝냅니다.

**2. 논문·실무에선 이렇게 쓴다** · 온라인 패널 조사에서 **5~15%** 수준으로 보고됩니다. 제외 기준과 인원을 방법 장에 명시합니다.

**3. 읽고 판단하는 법** · 복수 기준에 **동시에** 걸린 경우만 제외하세요. 단일 기준은 성실한 응답자까지 날립니다.

</div>

| 탐지 지표 | 계산 | 기준(경험적) | 잡아내는 유형 |
| --- | --- | --- | --- |
| 응답시간 | 전체 초 / 문항 수 | 문항당 2초 미만 | 속도위반 |
| 최장연속동일 (LongString) | 같은 값이 이어진 최대 길이 | 15 이상 | 직선반응 |
| 개인내 표준편차 (IRV) | 한 응답자의 전 문항 SD | < 0.3 (엄격 < 0.5) | 저변량 응답 |
| 역문항 불일치 | 정문항–역문항 개인 수준 일관성 | 부적 일관성 실패 | 무성의 응답 |
| 주의점검 문항 | '이 문항은 3번을 고르세요' | 오답 | 전반적 부주의 |
| 마할라노비스 거리 | 다변량 이상치 | χ² 임계값 초과 | 비전형 반응패턴 |

```r
library(careless)
items <- grep("^(SC|PC|CM|WE)_", names(d), value = TRUE)

d$longstring <- careless::longstring(d[items])
d$irv        <- careless::irv(d[items])
d$md         <- careless::mahad(d[items], plot = FALSE)
d$sec_item   <- d$resp_sec / length(items)

# 복수 기준 동시 충족만 제외
d$flag <- with(d, (longstring >= 15) + (irv < 0.30) +
                  (sec_item < 2) + (md > qchisq(.999, length(items))))
table(d$flag)
clean <- subset(d, flag <= 1)
```

!!! note "실습 데이터"
    `00_master_wide_RAW.csv`에 제외 전 468명이 `flag` 열과 함께 있습니다. flag 2=직선반응(21명), 3=패턴응답(7명), 4=시간미달(7명). 여기에 **플래그에 걸리지 않는 경미한 저변량 응답자 42명**이 섞여 있습니다 — 실제 자료에서 정제 후에도 IRV<.50이 8%대로 남는 현상을 재현한 것입니다. 기준선을 어디에 그을지 직접 판단해 보세요.

## 결측 — 기제를 먼저 판단한다

| 기제 | 뜻 | 예 | 권장 처리 |
| --- | --- | --- | --- |
| MCAR | 완전 무작위 결측 | 서버 오류로 임의 누락 | 어떤 방법도 편향 없음 |
| MAR | 관측변인으로 설명되는 결측 | 고연차일수록 임금 무응답 | **FIML · 다중대체** |
| MNAR | 결측값 자체가 원인 | 이직의도 높은 사람이 T2 이탈 | 민감도 분석 · 선택모형 |

| 방법 | N 손실 | 편향 | 권장도 |
| --- | --- | --- | --- |
| 목록별 삭제 | 큼 | MAR에서 편향 | 기본값이지만 최선은 아님 |
| 대응별 삭제 | 중간 | 공분산행렬 비일관 | SEM에서 문제 발생 |
| 평균 대체 | 없음 | 분산 과소추정 | 권장하지 않음 |
| FIML | 없음 | MAR 하에서 불편 | **SEM·다층의 표준** |
| 다중대체 (MI) | 없음 | MAR 하에서 불편 | **회귀 계열의 표준** |

```r
naniar::vis_miss(d); naniar::gg_miss_upset(d)
mice::md.pattern(d[vars])
naniar::mcar_test(d[vars])              # Little의 MCAR 검정

imp <- mice::mice(d[vars], m = 20, method = "pmm", seed = 2026)
fit <- with(imp, lm(WE_TOT ~ SC_TOT + PC_TOT + age))
summary(mice::pool(fit))

lavaan::sem(model, data = d, missing = "fiml")   # SEM·다층은 FIML
```

!!! note "패널 이탈은 특별 취급"
    종단연구의 T2·T3 이탈은 단위 무응답입니다. 이탈자와 잔류자의 T1 변인을 비교(attrition analysis)해 체계적 차이가 있는지 **반드시 보고**하세요. 실습 데이터는 T2 12%, T3 22% 이탈을 재현했습니다.

## 공통방법편의 — HRD 설문연구의 숙명

!!! abstract ""
    한 사람이 독립변인도 종속변인도 다 응답하면, 그 사람의 응답 성향 자체가 상관을 만듭니다. 이것을 방어하지 못하면 모든 계수가 의심받습니다.

### 사전 통제 — 설계 단계가 훨씬 효과적

- **시간 분리** — X와 Y를 2~4주 간격으로 측정 (가장 강력)
- **자료원 분리** — 성과는 상사 평정, 태도는 본인 응답
- **익명성 보장 명시** — 정답이 없음을 강조해 사회적 바람직성 완화
- **문항 순서 무작위화**, 척도 형식 변화
- **심리적 분리** — 블록 사이에 무관한 문항 삽입

### 사후 검증 — 세 가지 수준

| 방법 | 하는 일 | 기준 | 한계 |
| --- | --- | --- | --- |
| Harman 단일요인 | 전 문항 비회전 요인분석 | 제1요인 설명분산 < 50% | 검정력이 매우 낮음 — 이것만으로는 부족 |
| 잠재공통방법요인 | CFA에 방법요인 추가 | 적합도 개선 미미 · 부하 변화 작음 | 권장 수준 |
| 측정된 잠재표지 (MLMV) | 이론과 무관한 표지변인 투입 | 통제 전후 계수 비교 | 가장 강력하나 설계 필요 |

```r
fa <- psych::principal(d[items], nfactors = 1)
fa$values[1] / length(items) * 100      # < 50%

mod_cmv <- paste(measurement_model, "
  CMV =~ ", paste(items, collapse = " + "), "
  CMV ~~ 0*SC + 0*PC + 0*WE ")
f_cmv <- cfa(mod_cmv, data = d, estimator = "MLR")
semTools::compareFit(f_base, f_cmv)
```

!!! note "보고 문장 예"
    "공통방법편의를 통제하기 위해 독립변인과 종속변인을 4주 간격으로 분리 측정하였으며, 익명성을 보장하고 정답이 없음을 안내하였다. 사후 검증으로 Harman의 단일요인 검정을 실시한 결과 제1요인의 설명분산은 31.4%로 기준(50%)에 미달하였고, 잠재공통방법요인을 추가한 모형과의 적합도 차이도 미미하였다(ΔCFI = .004)."

### 이상치 — 지우기 전에 물어볼 것

1. **입력 오류인가** — 임금 2,000만원은 오타일 수도, 실제일 수도 있습니다.
2. **다른 모집단인가** — 임원 1명이 섞였다면 표본 정의를 다시 봐야 합니다.
3. **영향력이 있는가** — Cook's D, DFBETA로 계수를 실제로 흔드는지 확인.
4. **제외 시와 유지 시 결과가 달라지는가** — 다르다면 둘 다 보고하는 것이 정직합니다.

!!! warning "왜도가 큰 변인"
    임금·이직시도횟수·근속기간처럼 우편포된 변인은 로그변환을 고려하되, **변환 후 해석이 달라진다**는 점을 명시해야 합니다. 계수는 '1단위 증가'가 아니라 '1% 증가'의 효과가 됩니다.
