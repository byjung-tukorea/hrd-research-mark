## 왜(why)와 언제(when)

!!! abstract ""
    매개는 **왜**를, 조절은 **언제**를 답합니다. 이 둘을 구분하지 못하면 모형 전체가 흔들립니다.

| 매개 Mediation — '왜' | 조절 Moderation — '언제' |
| --- | --- |
| **X → M → Y**X가 M을 바꾸고, 바뀐 M이 Y를 바꿉니다.<br>교육 → 몰입 → 성과 (징검다리)M은 X 이후에 발생·측정효과가 *어떤 경로로* 일어나는지 설명간접효과 ab가 핵심 | **X × W → Y**W의 수준에 따라 X→Y의 기울기가 달라집니다.W는 X에 영향받지 않음효과가 *누구에게/언제* 큰지 설명상호작용항이 핵심 |

| 모형 | 구조 | 묻는 것 | PROCESS 모형 |
| --- | --- | --- | --- |
| 단순 매개 | X→M→Y | 통로가 무엇인가 | 4 |
| 직렬(이중) 매개 | X→M1→M2→Y | 통로가 연쇄적인가 | 6 |
| 단순 조절 | X×W→Y | 효과가 언제 강한가 | 1 |
| 조절된 매개 | X→M→Y의 일부 경로를 W가 조절 | 통로가 조건에 따라 열리나 | 7 · 14 · 58 |
| 매개된 조절 | X×W의 효과가 M을 거쳐 전달 | 상호작용이 왜 생기나 | — |
| 조절된 조절 | X×W×Z→Y | 조건의 조건이 있는가 | 3 |

## 매개 — Baron & Kenny에서 부트스트랩으로

### 고전적 4단계와 그 문제

1. X → Y 유의 (총효과 c)
2. X → M 유의 (경로 a)
3. M → Y 유의, X 통제 (경로 b)
4. X → Y 계수가 줄어듦 (c' < c)

문제는 **1단계**입니다. 총효과가 유의하지 않아도 간접효과는 존재할 수 있습니다(억제효과, 상반된 두 통로). 그래서 지금은 1단계를 필수 조건으로 보지 않습니다.

| 방법 | 원리 | 권장도 |
| --- | --- | --- |
| Sobel 검정 | ab의 표준오차로 Z 검정 | 간접효과 분포가 비정규 → 보조로만 |
| 부트스트랩 CI | 경험적 분포에서 직접 구간 추정 | **표준** · 5,000회 · 편향수정(BCa) |
| Monte Carlo CI | 모수 분포에서 시뮬레이션 | 원자료 없을 때 유용 |

### 부트스트랩이 표준인 이유

간접효과 ab는 두 계수의 **곱**이라 정규분포를 따르지 않습니다. 대개 편포된 분포가 되므로, 정규성을 가정하는 Sobel 검정은 검정력이 떨어집니다. 부트스트랩은 표본에서 반복 재추출해 ab의 **경험적 분포**를 직접 만들어 구간을 잡습니다.

```r
mod <- '
  PC_TOT ~ a*SC_TOT + sex + age + tenure_yr
  WE_TOT ~ b*PC_TOT + cp*SC_TOT + sex + age + tenure_yr
  ab    := a*b
  total := cp + a*b
  prop  := ab/total
'
fit <- sem(mod, data = d, se = "bootstrap", bootstrap = 5000)
parameterEstimates(fit, boot.ci.type = "bca.simple", standardized = TRUE)
```

!!! warning "'완전매개'라는 표현"
    c'이 유의하지 않다고 완전매개라 부르는 것은 검정력 문제일 뿐일 수 있습니다. 이분법 대신 **간접효과의 크기와 신뢰구간, 매개비율**로 서술하는 편이 정확합니다.

## 직렬 매개 — 통로의 연쇄

X → M1 → M2 → Y 구조에서는 간접효과가 **세 개** 생깁니다. 각각을 따로 검정하고, 서로 비교까지 해야 완결됩니다.

```r
mod <- '
  PC_TOT ~ a1*SC_TOT + sex + age
  CM_TOT ~ a2*SC_TOT + d21*PC_TOT + sex + age
  JP_TOT ~ cp*SC_TOT + b1*PC_TOT + b2*CM_TOT + sex + age

  ind1 := a1*b1          # SC → PC → JP
  ind2 := a2*b2          # SC → CM → JP
  ind3 := a1*d21*b2      # SC → PC → CM → JP  (직렬)
  total_ind := ind1 + ind2 + ind3

  c12 := ind1 - ind2     # 대비검정 — 어느 통로가 더 센가
  c13 := ind1 - ind3
  c23 := ind2 - ind3
'
fit <- sem(mod, data = d, se = "bootstrap", bootstrap = 5000, missing = "fiml")
parameterEstimates(fit, boot.ci.type = "bca.simple") |> filter(op == ":=")
```

!!! note "매개변인 순서의 근거"
    M1과 M2의 순서는 통계가 정해 주지 않습니다. 이론적 근거(시간적 선행, 개념적 위계)를 반드시 서술하고, 가능하면 역순 모형과 적합도를 비교해 보이세요.

## 조절 — 중심화, 단순기울기, J-N

### 절차

1. 예측변인과 조절변인을 **평균중심화** (다중공선성 완화 + 절편 해석 개선)
2. 위계적 투입: 통제 → 주효과 → 상호작용항
3. 상호작용항의 β와 **ΔR²** 확인
4. 유의하면 **단순기울기** 분석 (조절변인 ±1SD)
5. 가능하면 **Johnson–Neyman** 유의영역까지

!!! warning "중심화에 대한 오해"
    중심화는 상호작용항의 **계수 크기를 바꾸지 않습니다**. 바뀌는 것은 주효과의 해석(조절변인이 평균일 때의 효과)과 VIF입니다. '중심화해야 유의해진다'는 말은 사실이 아닙니다.

```r
d <- d |> mutate(SC_c = scale(SC_TOT, scale = FALSE)[,1],
                 PA_c = scale(PA_TOT, scale = FALSE)[,1])
h2 <- lm(TI_TOT ~ sex + age + tenure_yr + SC_c + PA_c, data = d)
h3 <- lm(TI_TOT ~ sex + age + tenure_yr + SC_c * PA_c, data = d)
anova(h2, h3)                                   # ΔR²

interactions::sim_slopes(h3, pred = SC_c, modx = PA_c, modx.values = "plus-minus")
interactions::interact_plot(h3, pred = SC_c, modx = PA_c, interval = TRUE)
interactions::johnson_neyman(h3, pred = SC_c, modx = PA_c)
```

### Johnson–Neyman이 ±1SD보다 나은 이유

±1SD는 임의의 두 지점일 뿐입니다. J-N은 **조절변인이 어느 값을 넘으면 효과가 유의해지는지** 그 경계를 알려줍니다. '학습지원문화가 3.42 이상인 조직에서만 자기자비의 효과가 유의하였다'처럼 실무적으로 훨씬 유용한 문장이 나옵니다.

!!! note "잠재변인 상호작용"
    관측변인이 아니라 잠재변인끼리 상호작용을 볼 때는 Mplus의 `XWITH` 명령이나 lavaan의 잔차중심화 곱항 접근을 씁니다. 측정오차가 상호작용항에서 증폭되는 문제를 다루기 위함입니다.

## 조건부 과정 — 조절된 매개의 판정 지표

!!! abstract ""
    조건부 간접효과를 여러 지점에서 나열하는 것만으로는 부족합니다. **조절된 매개 지수(IMM)**가 결론입니다.

### 조절된 매개 지수 (Index of Moderated Mediation)

<div class="tri" markdown>

**1. 쉽게 말해** · 조절변인이 1단위 변할 때 **간접효과가 얼마나 변하는가**를 하나의 수치로 만든 것입니다.

**2. 논문·실무에선 이렇게 쓴다** · "조절된 매개 지수는 −.21(95% CI [−.34, −.09])로 0을 포함하지 않아 조절된 매개효과가 지지되었다"

**3. 읽고 판단하는 법** · CI가 0을 포함하지 않아야 결론이 섭니다. 조건부 간접효과 나열만으로는 **두 효과가 서로 다르다는 증명이 안 됩니다**.

</div>

```r
# PROCESS 모형 14 (b 경로 조절) 에 해당
mod14 <- '
  PC_c   ~ a1*SC_c + sex + age
  TI_TOT ~ b1*PC_c + b2*LS_c + b3*PC_c:LS_c + cp*SC_c + sex + age

  IMM      := a1*b3           # ★ 조절된 매개 지수
  ind_lo   := a1*(b1 + b3*(-0.9))
  ind_mean := a1*b1
  ind_hi   := a1*(b1 + b3*( 0.9))
'
f14 <- sem(mod14, data = d, se = "bootstrap", bootstrap = 5000)
parameterEstimates(f14, boot.ci.type = "bca.simple")
```

### 3원 상호작용(조절된 조절)

- 세 변인의 **모든 2원 상호작용항**을 먼저 투입해야 3원항 해석이 성립합니다.
- 검정력이 크게 떨어지므로 표본이 충분해야 합니다.
- 결과 해석은 반드시 **2×2 형태의 도표**로 제시하세요. 계수만으로는 아무도 읽지 못합니다.

!!! note "PROCESS 모형 번호를 명시하세요"
    SPSS PROCESS 매크로를 썼다면 모형 번호(4, 6, 7, 14, 58 등)를 밝히세요. 재현성이 크게 올라가고 심사자가 모형 구조를 즉시 파악합니다. 이 강의 데이터는 모형 14 구조를 심어 두었습니다.
