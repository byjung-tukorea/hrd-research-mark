# M0 · 오리엔테이션과 통계 문해

> 기호를 읽는 법 — 계산이 아니라 개념·용어·해석 기준

## 이 여덟 시간이 하려는 것

!!! abstract ""
    통계를 처음부터 배우지 않습니다. **개념 · 용어 · 해석 기준**을 연구자의 기본 역량으로 깔아 두는 시간입니다.

HRD 분야 학위논문의 심사평은 대체로 세 갈래로 갈립니다. '이 변인 관계를 왜 이렇게 설정했는가', '이 척도로 이 개념을 잰다고 볼 수 있는가', '이 분석이 이 자료구조에 맞는가'. 통계 계산이 틀려서 떨어지는 논문은 드물고, 이 세 질문에 답하지 못해 막히는 논문이 대부분입니다.

### 왜 연구자에게 통계 문해가 기본 역량인가

| 이유 | 내용 |
| --- | --- |
| 의사결정 | 분석 결과를 근거로 사람·조직에 관한 주장을 편다 — 오독은 곧 잘못된 결론 |
| 비판적 검증 | 선행연구와 벤더 리포트를 곧이곧대로 받지 않고 숫자를 의심하고 따져본다 |
| 소통·설득 | 심사위원·현업에 '이 숫자가 무슨 뜻인지'를 번역해 설득한다 |
| 자생력 | 새로운 기법이 나와도 기본 개념이 깔려 있으면 스스로 따라잡는다 |

## 모든 개념을 3단으로 푼다

!!! abstract ""
    어떤 통계 용어가 나와도 항상 같은 틀로 분해합니다. 이 강의 전체가 이 구조로 되어 있습니다.

### 예시 — 표준편차 (SD)

<div class="tri" markdown>

**1. 쉽게 말해** · 평균 주변에 사람들이 얼마나 흩어져 있는가. 같은 평균 3.5여도 다 비슷하게 답한 조직과 극단으로 갈린 조직은 완전히 다릅니다.

**2. 논문·실무에선 이렇게 쓴다** · 기술통계 표의 두 번째 열에 항상 M과 함께 등장합니다. `M = 3.15 (SD = 0.92)`

**3. 읽고 판단하는 법** · SD가 평균의 절반을 넘으면 분포가 넓다는 신호입니다. 5점 척도에서 SD가 1.2를 넘으면 응답이 양극화됐는지 히스토그램을 확인하세요.

</div>

이 틀은 통계를 **정복하게** 만드는 것이 아니라 **숫자 앞에서 당당하게** 만듭니다. 세 번째 칸이 핵심입니다 — 그 숫자를 보고 무엇을 판단할지 기준이 있어야 결과를 쓸 수 있습니다.

!!! quote "읽기 · 심화 경로"
    - `S4` 이 3단 분해 프레임은 「LG인화원 HR Analytics 통계기본역량」의 교수 설계를 학위논문 맥락으로 옮긴 것입니다.

## 기호 사전 ① — 기술통계

| 기호 | 한 줄 풀이 | 읽는 법 |
| --- | --- | --- |
| *M* | 평균 | 대표값. 단 왜도가 크면 대표하지 못함 |
| *SD* | 표준편차 — 흩어진 정도 | 평균의 절반을 넘으면 넓은 분포 |
| *Mdn* | 중앙값 | 왜도가 클 때 M과 함께 반드시 병기 |
| *N* / *n* | 전체 표본 / 하위집단 표본 | 표마다 N이 다르면 결측 처리를 밝혀야 함 |
| % | 비율 | 분모를 명시하지 않으면 오독됨 |
| Skew | 왜도 — 좌우 치우침 | |왜도| < 2 이면 모수검정 가능 |
| Kurt | 첨도 — 뾰족한 정도 | |첨도| < 7 |
| Min–Max | 최소–최대 | 이상치와 입력오류를 잡는 첫 관문 |

### 평균의 함정

"평균 연봉 8,000만 원"이 모두를 대표하지는 않습니다. 소수의 고소득자가 평균을 끌어올리는 착시입니다. 이럴 때는 **중앙값을 함께** 봐야 현실이 보입니다.

!!! warning "분포를 쪼개 보라"
    부서 평균 몰입도가 높아도 한쪽은 매우 높고 한쪽은 번아웃일 수 있습니다. 평균·중앙값·분포를 한 세트로 보고하는 습관을 들이세요. 실습 데이터의 임금 변인이 정확히 이 구조입니다 — 왜도 4.1에 극단치 6건.

## 기호 사전 ② — 관계·검정

| 기호 | 한 줄 풀이 | 기준선 |
| --- | --- | --- |
| *r* | 상관계수 — 함께 움직이는 정도 | −1~+1 · .10/.30/.50 소·중·대 · **인과 아님** |
| β | 표준화 회귀계수 — 영향력의 방향과 크기 | 다른 변인 통제 후 상대 비교용 |
| *B* | 비표준화 계수 — 실제 단위 변화 | 실무·정책 함의를 말할 때 |
| *R*² | 설명력 — Y를 몇 % 설명하나 | adjusted R²를 반드시 병기 |
| *p* | 유의확률 — 우연일 확률 | < .05 · .01 · .001 · **크기가 아님** |
| *t* / *F* | 차이 검정값 | 자유도와 함께 보고 |
| χ² | 빈도 괴리 · 모형 적합도 | 표본 크기에 민감 |
| α | 신뢰도 — 문항 일관성 | ≥ .70 (탐색 .60) |
| *d* / η² / *f*² | 효과크기 — 차이·영향의 실제 크기 | .2·.5·.8 / .01·.06·.14 / .02·.15·.35 |
| OR / HR | 승산비 / 위험비 | 기준 1 · CI가 1을 포함하면 비유의 |
| CFI / RMSEA | 모형 적합도 | ≥ .90 / ≤ .08 |
| ICC | 급내상관 — 집단 소속의 설명력 | ≥ .05~.10 이면 다층 필요 |

!!! note "별표 표기"
    * *p* < .05 · ** *p* < .01 · *** *p* < .001. 학술지마다 관례가 다르니 투고 규정을 확인하세요.

## 피해야 할 여섯 가지 함정

!!! abstract ""
    분석 전에, 그리고 보고 전에 스스로 점검하는 목록입니다.

01. **상관 = 인과 단정** — 함께 움직인다고 원인은 아닙니다. 횡단자료는 '관련'까지만 말할 수 있습니다.
02. **p값 사냥** — 유의할 때까지 변인을 바꿔 가며 돌려보는 것. 분석계획을 먼저 확정하세요.
03. **표본 편향** — 누가 빠졌는지 물으세요. 응답자만의 이야기일 수 있습니다.
04. **평균의 함정** — 이상치와 분포를 무시한 대표값. 중앙값과 분포를 함께 보세요.
05. **유의함 = 중요함** — N이 크면 사소한 차이도 유의합니다. 효과크기로 실질적 크기를 확인하세요.
06. **측정 무시** — 신뢰도·타당도가 확보되지 않은 데이터로 하는 분석은 모두 무의미합니다.
