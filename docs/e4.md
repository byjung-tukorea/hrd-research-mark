# E4 · 지식의 통합과 응용 연구

> 문헌연구·메타분석·역량모델링·Q방법론·피플 애널리틱스

## 문헌연구 — 읽는 것이 곧 방법

!!! abstract ""
    문헌고찰은 서론의 준비 작업이 아니라 **그 자체로 독립된 연구방법**입니다. 유형에 따라 절차와 산출이 완전히 다릅니다.

| 유형 | 목적 | 절차의 엄격성 | 산출 |
| --- | --- | --- | --- |
| 서술적 고찰 | 분야 개관 | 낮음 | 맥락적 이해 |
| 체계적 문헌고찰 | 특정 질문에 대한 근거 종합 | **매우 높음** · PRISMA | 근거의 강도 판정 |
| 통합적 고찰 | 이론·실증을 아울러 통합 | 중간 | 새로운 개념틀 |
| 범위 고찰 (scoping) | 연구 지형 파악 | 중간 · PRISMA-ScR | 지식 지도와 공백 |
| 메타분석 | 효과크기의 통계적 종합 | 매우 높음 | 평균 효과크기 |
| 이론적 고찰 | 이론 발전·비판 | 해석적 | 새 명제 |

### 체계적 문헌고찰의 최소 요건

1. **사전 등록된 프로토콜** — 검색 전에 질문·기준을 확정
2. **검색 전략** — DB, 검색어, 기간, 언어를 재현 가능하게 기술
3. **선정·배제 기준** — 사전에 정의
4. **PRISMA 흐름도** — 검색 → 중복제거 → 초록선별 → 전문검토 → 최종 포함
5. **복수 평정자** — 선별과 자료추출에 2인 이상, 일치도 보고
6. **질 평가** — 포함 연구의 방법론적 질 평정

!!! quote "읽기 · 심화 경로"
    - `S3` ⑦ 문헌연구(이재영) pp. 173–188 — 문헌고찰의 중요성 · 유형 · 연구 가이드

## 메타분석 — 효과크기를 종합한다

### 메타분석

<div class="tri" markdown>

**1. 쉽게 말해** · 같은 주제를 다룬 여러 연구의 결과를 **통계적으로 합쳐** 평균 효과크기를 냅니다.

**2. 논문·실무에선 이렇게 쓴다** · "교육훈련이 직무성과에 미치는 효과의 평균 크기는 d = .42(95% CI [.35, .49])였다"

**3. 읽고 판단하는 법** · 이질성(I²)이 크면 평균값만으로는 부족합니다. **조절변인 분석**으로 왜 다른지 설명해야 합니다.

</div>

### 절차

1. 연구 질문과 **PICO**(대상·개입·비교·결과) 정의
2. 체계적 검색과 선별 (PRISMA)
3. **효과크기 추출** — d, r, OR 등으로 통일 변환
4. **분석 모형 선택** — 고정효과 vs 무선효과
5. **이질성 검정** — Q 통계량, I²
6. **조절변인 분석** — 메타회귀 · 하위집단 분석
7. **출판편향 검토** — 깔때기 도표, Egger 검정, trim-and-fill

| 고정효과 모형 | 무선효과 모형 |
| --- | --- |
| 모든 연구가 **하나의 참 효과**를 추정한다고 가정.<br><br>연구 간 차이는 표집오차뿐.<br>동질적인 소수의 연구에 적합. | 연구마다 **참 효과가 다르다**고 가정.<br><br>사회과학에서는 대개 이쪽.<br>일반화 범위가 넓습니다. |

| I² | 해석 |
| --- | --- |
| 25% 내외 | 낮은 이질성 |
| 50% 내외 | 중간 |
| 75% 이상 | 높음 — 조절변인 분석 필수 |

!!! warning "출판편향"
    유의한 결과가 더 잘 출판되므로, 문헌만 모으면 효과가 과대추정됩니다. 깔때기 도표의 비대칭, Egger 검정, trim-and-fill을 **반드시** 보고하고, 가능하면 학위논문·미발표 자료까지 포함(gray literature)하세요.

!!! quote "읽기 · 심화 경로"
    - `S3` ⑧ 메타분석(이윤수) pp. 193–206 — 정의 · 필요성 · 절차 · 분석 모형 · 출판 편향

## 역량모델링과 Q방법론

### 역량모델링 — HRD에 가장 특화된 방법

특정 직무·역할에서 **고성과자를 구별하는 행동특성**을 도출하는 절차입니다. 순수 연구방법이라기보다 연구와 실무가 만나는 지점에 있습니다.

| 접근 | 방식 | 특징 |
| --- | --- | --- |
| 행동사건면접 (BEI) | 고성과자의 결정적 사건 심층면접 | 귀납적 · 시간 많이 소요 |
| 직무분석 기반 | 과업 분해 후 요구 역량 도출 | 체계적 · 미래 역량에 약함 |
| 전문가 패널 / 델파이 | 전문가 합의로 역량 도출 | 빠름 · 현장 근거는 약함 |
| 문헌·벤치마킹 | 기존 모델 참조 후 수정 | 효율적 · 맥락 특수성 부족 |
| 혼합 | 위를 조합 | **가장 흔한 실제 방식** |

- 도출 후에는 **타당화**가 필요합니다 — 내용타당도(전문가 평정 CVR), 구인타당도(요인분석), 준거타당도(성과와의 관련).
- 역량 정의는 **관찰 가능한 행동**으로 진술해야 합니다. '주도성이 높다'가 아니라 '요청받기 전에 문제를 발견하고 대안을 제시한다'.
- 수준(level)을 나눈다면 각 수준의 행동지표를 명시해야 평가에 쓸 수 있습니다.

### Q방법론 — 주관성을 체계적으로 다루는 법

'사람들이 이 주제를 어떻게 보는가'를 **유형화**합니다. 응답자가 진술문 카드를 정규분포 격자에 강제 배열(Q-sort)하고, **사람을 요인분석**합니다 — 일반 요인분석이 문항을 묶는다면 Q는 사람을 묶습니다.

1. **Q모집단** — 해당 주제에 관한 모든 진술 수집 (면담·문헌·미디어)
2. **Q표본** — 대표성 있게 30~60개 진술 선별
3. **P표본** — 다양한 관점을 대표할 응답자 선정 (대표성보다 다양성)
4. **Q분류** — 강제분포 격자에 배열
5. **요인분석** — 주성분 또는 센트로이드 + 배리맥스 회전
6. **유형 해석** — 각 요인의 대표 진술과 유형명 부여

!!! note "Q는 소표본이 정상"
    Q방법론은 일반화가 목적이 아니라 **존재하는 관점의 유형**을 밝히는 것이 목적입니다. P표본 30~50명이면 충분하며, 표본 크기로 비판받을 때 이 논리로 방어합니다.

!!! quote "읽기 · 심화 경로"
    - `S3` ⑨ 역량모델링 연구(박용호) pp. 211–229
    - `S3` ⑪ Q방법론(백평구) pp. 265–280 — Q연구의 절차 · HRD 논문 작성

## 피플 애널리틱스 — 연구와 실무의 접점

!!! abstract ""
    HR 데이터로 사람과 조직에 관한 의사결정을 내리는 실천입니다. 사회과학 양적연구의 **전통 위에** 서 있으면서, 목적과 제약이 다릅니다.

| 학술 연구 | 피플 애널리틱스 |
| --- | --- |
| **목적** 이론 검증과 일반화<br>**자료** 설계된 설문·실험<br>**시간** 수개월~수년<br>**산출** 논문<br>**기준** 방법론적 엄격성 | **목적** 의사결정 지원<br>**자료** HRIS·근태·성과 등 **기존 데이터**<br>**시간** 수일~수주<br>**산출** 대시보드·제언<br>**기준** 실행가능성과 신뢰 |

### 성숙도 단계

| 단계 | 질문 | 기법 |
| --- | --- | --- |
| 기술 (descriptive) | 무슨 일이 있었나 | 기술통계 · 대시보드 |
| 진단 (diagnostic) | 왜 그랬나 | 상관 · 회귀 · 집단 비교 |
| 예측 (predictive) | 앞으로 어떻게 될까 | 머신러닝 · 생존분석 |
| 처방 (prescriptive) | 무엇을 해야 하나 | 최적화 · 시나리오 · 인과추론 |

### 비정형 데이터의 활용

자유응답 서베이, 퇴사 면담 기록, 협업툴 로그, 직무기술서 등 **텍스트**가 HR 데이터의 상당 부분입니다. 텍스트마이닝(E1 참조)이 여기서 결합됩니다.

!!! warning "윤리와 신뢰"
    사람에 관한 데이터는 다르게 다뤄야 합니다. **목적 제한**(수집 목적 외 사용 금지), **투명성**(무엇을 왜 분석하는지 구성원에게 알림), **설명가능성**(블랙박스 모델로 인사 결정을 내리지 않음), **차별 방지**(모델이 특정 집단에 불리하게 작동하지 않는지 점검). 예측 정확도보다 이쪽이 먼저입니다.
