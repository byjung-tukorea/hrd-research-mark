# M1 · 연구 패러다임과 설계

> 무엇을 묻고 있는가 — 패러다임 선택에서 분석전략까지

## 두 세계관 — 실증주의와 해석주의

!!! abstract ""
    연구방법을 고르기 전에, 내가 어떤 세계관 위에 서 있는지를 알아야 합니다. 방법은 세계관의 결과이지 그 반대가 아닙니다.

| 실증주의 — 양적연구 | 해석주의 — 질적연구 |
| --- | --- |
| **존재론** 실재는 하나이며 관찰 가능하다<br>**인식론** 연구자는 대상과 분리된다<br>**목적** 일반화 가능한 법칙의 발견<br>**논리** 연역 — 이론에서 가설로<br>**산출** 수치 · 통계적 검정 | **존재론** 실재는 다중이며 구성된다<br>**인식론** 연구자와 참여자는 상호작용한다<br>**목적** 맥락 안에서의 의미 이해<br>**논리** 귀납 — 자료에서 개념으로<br>**산출** 텍스트 · 두터운 기술 |

### 어떤 질문이 어디로 가는가

| 연구 질문의 형태 | 적합한 접근 | HRD 예시 |
| --- | --- | --- |
| 얼마나 · 몇 명이 · 어느 정도 | 양적 | 교육 참여가 이직의도를 낮추는가 |
| 어떻게 · 왜 그렇게 경험하는가 | 질적 | 경력 전환자는 학습을 어떻게 의미화하는가 |
| 무엇이 존재하는가 (개념 미확립) | 질적 → 양적 | 일터에서의 '심리적 안전감'은 어떤 요소로 구성되는가 |
| 이 관계가 맥락에 따라 왜 다른가 | 혼합 | 같은 프로그램이 A사에선 되고 B사에선 안 되는 이유 |

### 혼합연구 — 두 길의 교차로

- **순차적 탐색** (질적 → 양적) — 개념을 발견하고 척도를 만든 뒤 검증
- **순차적 설명** (양적 → 질적) — 통계 결과의 이유를 인터뷰로 규명
- **수렴적 병렬** — 두 자료를 동시에 수집해 삼각검증
- **내재적 설계** — 한쪽을 주로 하고 다른 쪽을 보조로

!!! warning "혼합연구의 오해"
    양적과 질적을 그냥 둘 다 하는 것은 혼합연구가 아닙니다. **통합 지점(point of interface)**이 설계에 명시되어야 합니다 — 어느 단계에서 두 자료가 만나 무엇을 산출하는지.

!!! quote "읽기 · 심화 경로"
    - `S3` ① 과학적 HRD 연구(김태성) pp. 3–17 — 무엇을·어떻게 연구할 것인가, 연구의 정당화
    - `S3` ⑤ 질적연구 설계(강현주) pp. 107–130 · ⑥ 근거이론(유기웅) pp. 135–168
    - `S2` 제1부 Ch.1 1차시 「질적연구와 양적연구 — 두 패러다임이 묻는 것들」
    - `S1` Ch.1 1차시 질적연구 vs 양적연구 (표 1-1 비교 매트릭스)

## 설명할 것인가, 예측할 것인가

!!! abstract ""
    추론통계와 머신러닝은 경쟁 관계가 아니라 **목적이 다른 두 문화**입니다. HRD 연구자는 둘의 경계를 알아야 합니다.

| 설명의 문화 — 추론통계 | 예측의 문화 — 머신러닝 |
| --- | --- |
| 모수를 추정하고 **왜**를 해석합니다.<br><br>· 계수 β의 방향과 크기가 결론<br>· 표본에서 모집단으로 일반화<br>· 가정(정규성·독립성)이 중요<br>· 이론 검증에 강함<br><br>*무엇이 이직을 유발하는가* | 새 관측치를 **얼마나 잘 맞히는가**가 목적입니다.<br><br>· 교차타당화 성능이 결론<br>· 해석보다 정확도<br>· 가정이 느슨함<br>· 변인이 많아도 작동<br><br>*누가 이직 위험이 높은가* |

### 선택 기준

| 연구 목적 | 선택 | 보고할 것 |
| --- | --- | --- |
| 이론적 기제 규명 | 추론통계 | β, p, 95% CI, 효과크기 |
| 정책·개입의 근거 확보 | 추론통계 (+ 인과추론 설계) | 통제된 계수, 반사실 논거 |
| 고위험군 조기 식별 | 머신러닝 | AUC, 정밀도·재현율, 교차타당화 |
| 변인이 많고 관계가 비선형 | 머신러닝 + 해석기법 | 변수중요도, SHAP |

!!! note "두 문화의 만남"
    최근에는 인과추론(causal inference)과 해석가능 머신러닝(interpretable ML)이 두 문화를 잇고 있습니다. 학위논문 수준에서는 '어느 쪽을 왜 택했는가'를 방법론 장에 명시하는 것으로 충분합니다.

!!! quote "읽기 · 심화 경로"
    - `S2` 제1부 Ch.1 2차시 「추론통계와 머신러닝 — 설명할 것인가, 예측할 것인가」 (표 1-2 연구문제 유형별 적합 방법론)
    - `S1` Ch.1 2차시 · 학습 점검 문제 · AI 활용 팁
    - `S4` 블록 4 「설명 vs 예측 — 통계와 머신러닝의 접점」

## 연구문제가 분석을 결정한다

!!! abstract ""
    분석기법을 먼저 고르고 거기에 연구문제를 맞추는 순서는 반드시 심사에서 드러납니다. 순서는 언제나 **문제 → 설계 → 분석**입니다.

### 연구문제의 일곱 문형

| 문형 | 묻는 것 | 자연스러운 분석 |
| --- | --- | --- |
| 관계형 | A와 B는 어떤 관계인가 | 상관 · 회귀 |
| 차이형 | 집단 간 A는 다른가 | t · ANOVA · 카이제곱 |
| 과정형 | A는 *왜* B에 영향을 주는가 | 매개분석 |
| 조건형 | A→B는 *언제* 강해지는가 | 조절분석 |
| 맥락형 | 그 관계가 조직마다 다른가 | 다층모형 · 무선기울기 |
| 변화형 | A와 B 중 무엇이 먼저인가 | 자기회귀교차지연 |
| 유형형 | 사람들이 몇 유형으로 갈리는가 | 잠재프로파일분석 |

### 같은 두 변인, 일곱 개의 연구

'자기자비'와 '이직의도' 두 변인만으로도 위 일곱 문형이 모두 성립합니다. 이 강의의 실습 데이터가 정확히 그렇게 설계되어 있어, 같은 자료로 일곱 가지 분석을 모두 돌려 볼 수 있습니다.

!!! warning "자주 나오는 지적"
    '매개효과와 조절효과를 모두 검증하였다'는 문장이 이론적 근거 없이 등장하면, 가설이 아니라 분석 메뉴를 나열한 것으로 읽힙니다. 각 경로에는 그 경로를 예상한 이론적 이유가 붙어야 합니다.

## 변인의 다섯 가지 역할

연구모형 도식을 그리는 순간 분석은 거의 결정됩니다. 각 변인이 맡은 역할을 먼저 확정하세요.

| 역할 | 한 줄 정의 | HRD 예시 | 오해하기 쉬운 점 |
| --- | --- | --- | --- |
| 독립 X | 결과를 만들어낸다고 보는 것 | 리더십 교육 참여 | '선행'과 '원인'은 다릅니다 |
| 종속 Y | 설명·예측하려는 것 | 팀 성과 · 이직의도 | Y가 여럿이면 별도 모형인지 밝힐 것 |
| 매개 M | 원인이 결과로 가는 **통로** | 직무몰입 | X 이후, Y 이전에 측정돼야 논리가 섬 |
| 조절 W | 효과의 크기를 바꾸는 **조건** | 팀 규모 · 학습지원문화 | M과 가장 자주 혼동됩니다 |
| 통제 C | 영향을 빼고 봐야 할 것 | 근속 · 연령 · 직급 | '다 넣으면 안전'은 오해 |

| 매개 M — **왜** | 조절 W — **언제** |
| --- | --- |
| X가 M을 *변화시키고*, 변화한 M이 Y를 바꿉니다.<br><br>**X → M → Y**<br><br>시간 순서와 이론적 기제가 필요합니다. | W는 X에 의해 변하지 않습니다. W의 수준에 따라 X→Y의 기울기만 달라집니다.<br><br>**X × W → Y** |

!!! note "판별 요령"
    'X를 높이면 W도 높아질까?'라고 물어보세요. 그렇다면 조절변인이 아니라 매개변인일 가능성이 큽니다. 성별·연령·조직규모처럼 X가 바꿀 수 없는 변인은 조절변인 후보로 안전합니다.

### 좋은 가설의 네 조건

1. **방향성** — '관계가 있을 것이다'가 아니라 '정적일 것이다'
2. **검증가능성** — 반증될 수 있는 형태로 진술
3. **이론적 근거** — 어느 이론의 어느 명제에서 나왔는가
4. **구체성** — 어떤 모집단에서, 어떤 조건에서

    - `S4` 블록 1 「변수의 5가지 역할 — 같은 데이터도 배치가 다르다」

## 이론적 틀과 설계의 세 축

### HRD·조직행동에서 자주 쓰이는 틀

| 이론 | 핵심 논리 | 전형적 모형 |
| --- | --- | --- |
| 자원보존이론 (COR) | 자원 손실은 소진을, 획득은 열의를 낳는다 | 자원 → 소진/열의 → 성과·이직 |
| 직무요구-자원 (JD-R) | 요구는 소진 경로, 자원은 동기 경로 | 이중경로 매개모형 |
| 사회교환이론 (SET) | 조직의 대우에 구성원이 호혜로 응답한다 | 지원인식 → 교환관계 → 태도 |
| 자기결정이론 (SDT) | 자율성·유능감·관계성이 내재동기를 만든다 | 욕구충족 매개모형 |
| 사회인지진로이론 (SCCT) | 효능감과 결과기대가 목표·행동을 만든다 | 효능감 → 목표 → 행동 |
| 전이이론 | 학습이 현장으로 옮겨가는 조건 | 학습 × 전이풍토 → 전이 |

이론을 쓰는 데는 세 수준이 있습니다. **인용**(이름만 언급) — 가장 약합니다. **도출**(명제에서 가설을 연역) — 학위논문의 기본선입니다. **확장**(이론이 다루지 않은 경계조건 검증) — 기여가 분명해집니다.

### 설계의 세 축

| 축 | 선택지 | 연구에 미치는 영향 |
| --- | --- | --- |
| 시간 | 횡단 / 시차 / 종단패널 / 일지 | 인과 주장의 강도. 횡단은 '관련'까지만 |
| 자료원 | 단일응답자 / 다중응답자 / 객관지표 | 공통방법편의 방어력이 완전히 달라짐 |
| 표집 | 편의 / 층화 / 군집 / 패널사 | 일반화 범위와 다층분석 가능 여부 |

!!! note "시차설계 — 비용 대비 효과가 가장 큰 선택"
    전면 종단이 어렵다면 독립변인과 종속변인을 **2~4주 간격으로 분리 측정**하는 것만으로도 공통방법편의와 역인과 우려가 크게 줄어듭니다. HRD 현장 연구에서 가장 현실적인 절충안입니다.

## 표본 — 몇 명이면 충분한가

| 분석 | 최소 권장 | 근거 |
| --- | --- | --- |
| 다중회귀 | 예측변인당 15~20명 또는 G*Power | f²=.15, α=.05, 1−β=.80 |
| 매개 (부트스트랩) | 150~200 이상 | 간접효과 검정력은 주효과보다 낮음 |
| CB-SEM | 200 이상, 모수당 5~10명 | 모수 수가 표본 요구를 결정 |
| PLS-SEM | 최대 화살표 수 × 10 (경험칙) | 이 규칙은 과소추정 비판이 있음 |
| HLM | 집단 30개 이상, 집단당 5명 이상 | 집단 수가 적으면 τ 추정이 불안정 |
| LPA | 300 이상 권장 | 계층 수가 늘수록 요구가 급증 |
| 종단 (3파) | 이탈률 20~30% 감안해 초기 표본 확대 | FIML로도 한계가 있음 |

### G*Power 사전 검정력 분석

1. **Test family** — F tests (회귀·ANOVA) / t tests / χ² tests 중 선택
2. **Statistical test** — Linear multiple regression: Fixed model, R² increase 등
3. **Type of power analysis** — **A priori** (사전 산출) ← 이것을 쓰세요
4. 효과크기 f²(.15), α(.05), Power(.80), 예측변인 수 입력
5. 산출된 최소 표본을 보고 문장에 인용

!!! note "보고 문장 예"
    "선행연구의 효과크기(f² = .15)를 근거로 유의수준 .05, 검정력 .80, 예측변인 8개를 가정하여 G*Power 3.1로 산출한 결과 최소 표본은 109명이었으며, 본 연구는 433명을 확보하였다."

!!! warning "사후 검정력의 문제"
    분석이 끝난 뒤 관찰된 효과크기로 계산하는 사후 검정력(observed power)은 p값의 재표현일 뿐이라는 비판이 확립돼 있습니다. **사전 산출**을 하고, 이미 늦었다면 신뢰구간의 폭으로 정밀도를 논하세요.

!!! quote "읽기 · 심화 경로"
    - `S2` 제2부 Ch.2 4차시 「표본설계와 표본크기 — 몇 명이면 충분한가, 누구를 뽑을 것인가」
    - `S1` Ch.2 3차시 표본설계와 표본크기

## 실습 1 — 내 연구를 한 장으로

!!! abstract ""
    지금 진행 중인(또는 구상 중인) 연구를 아래 일곱 칸에 채워 보세요. 채워지지 않는 칸이 곧 지금의 약점입니다.

Q1
:   연구문제를 **의문문 한 문장**으로. '~을 알아본다'가 아니라 '~인가?'로.

Q4
:   이 모형을 지지하는 **주된 이론 하나**와 그 이론의 어떤 명제에서 나왔는지.

Q5
:   시간·자료원·표집 세 축에서 내 설계의 위치와, 그 선택의 대가는.

Q6
:   목표 표본 수와 그 근거(G*Power 또는 분석별 경험칙).

Q7
:   이 연구가 **기존 연구에 더하는 것**을 한 문장으로. '검증하였다'는 기여가 아닙니다.
