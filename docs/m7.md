## 측정오차를 걷어낸다는 것

!!! abstract ""
    회귀는 변인을 **오차 없이 측정했다고 가정**합니다. 척도의 신뢰도가 .80이면 20%는 오차인데, 회귀는 그것을 모른 채 계수를 추정합니다.

### 구조방정식모형 (SEM)

<div class="tri" markdown>

**1. 쉽게 말해** · 여러 화살표로 이루어진 모형 전체를 한 번에 검증합니다. 설문 문항 뒤에 숨은 '진짜 개념'을 추정해 개념 사이의 관계를 봅니다.

**2. 논문·실무에선 이렇게 쓴다** · 논문의 **그림 1(연구모형)**이 그대로 통계 모형이 됩니다. 측정모형 표 + 구조모형 표 + 경로도 세 가지가 세트입니다.

**3. 읽고 판단하는 법** · 적합도(χ²/df, CFI, TLI, RMSEA, SRMR)를 먼저 보고, 통과하면 경로계수를 읽습니다. **적합도 미달 모형의 계수는 해석하지 않습니다**.

</div>

### 측정오차가 하는 일

- **독립변인**의 오차 → 계수를 0쪽으로 **축소(attenuation)**시킵니다.
- **통제변인**의 오차 → 통제가 불완전해져 다른 계수가 **과대**추정됩니다.
- **상호작용항**은 두 변인의 신뢰도가 곱해져 축소가 더 심합니다.

### CB-SEM과 PLS-SEM

| 기준 | CB-SEM (lavaan · Amos · Mplus) | PLS-SEM (SmartPLS · seminr) |
| --- | --- | --- |
| 목적 | 이론 **검증** · 모형 적합 | **예측** · 이론 개발 |
| 추정 | 공분산행렬 재현 (ML) | 반복 최소자승 (성분 기반) |
| 표본 | 200 이상 권장 | 작은 표본에서도 수렴 |
| 정규성 | ML은 다변량 정규 가정 | 분포 가정 없음 |
| 적합도 | CFI·TLI·RMSEA·SRMR 풍부 | SRMR 정도 |
| 형성적 구인 | 까다로움 | **자연스러움** |
| 유의성 | 표준오차 기반 | **부트스트랩 필수** |

!!! warning "선택의 정당화"
    "표본이 작아서 PLS를 썼다"는 최근 비판받는 논거입니다. **예측 목적**, **형성적 구인 포함**, **복잡한 모형** 중 하나를 근거로 대는 편이 방어에 유리합니다.

    - `S2` 제3부 Ch.4 1차시 「SEM의 설계」 — SEM 설계 체크리스트 10항목

## CB-SEM — 2단계 접근

!!! abstract ""
    측정모형이 적합하지 않은 상태에서 구조모형 계수를 해석하는 것은 **고장난 자로 잰 값**을 논하는 것과 같습니다.

### 순서

1. **1단계 측정모형(CFA)** — 적합도, λ, AVE, CR, HTMT 확보
2. **2단계 구조모형(SEM)** — 경로계수 추정 및 해석
3. 필요 시 **2차 요인모형** 정당화 (Target coefficient ≥ .90)
4. 간접효과가 있다면 **부트스트랩**

### 적합도 — 세트로 보고

| 지표 | 수용 | 양호 | 성격 |
| --- | --- | --- | --- |
| χ²/df | ≤ 3 | ≤ 2 | 표본에 민감 |
| CFI · TLI | ≥ .90 | ≥ .95 | 상대적합 · N<200에서 과소추정 |
| RMSEA | ≤ .08 | ≤ .06 | 절대적합 · **90% CI 상한까지** |
| SRMR | ≤ .08 | ≤ .05 | 잔차 기반 |

!!! warning "지수 하나만 고르면 체리피킹"
    CFI만 좋고 RMSEA는 나쁜데 CFI만 보고하면 반드시 지적됩니다. 네 지수를 모두 제시하고, 미달 지수에 대한 해석을 덧붙이세요.

### 수정지수(MI)를 쓸 때

MI가 크다고 무조건 오차상관을 추가하면 **자료에 모형을 맞추는** 일이 됩니다. 같은 하위요인 내 문항, 역문항끼리처럼 **내용적 이유가 있을 때만** 허용하고, 그 이유를 본문에 씁니다.

```r
f1 <- cfa(cfa1, data = d, estimator = "MLR", missing = "fiml")
fitMeasures(f1, c("chisq","df","cfi","tli","rmsea","rmsea.ci.upper","srmr"))
modindices(f1, sort = TRUE, maximum.number = 15)

fs <- sem(structural, data = d, estimator = "MLR", missing = "fiml",
          se = "bootstrap", bootstrap = 2000)
summary(fs, standardized = TRUE, fit.measures = TRUE, rsquare = TRUE)
semPlot::semPaths(fs, "std", layout = "tree2")
```

## PLS-SEM — 예측을 겨냥할 때

### 평가 순서

1. **측정모형** — 외부적재 ≥ .70, AVE ≥ .50, rhoC ≥ .70, HTMT < .85
2. **구조모형** — 내부 VIF < 5, 경로계수, R², f²
3. **유의성** — 부트스트랩 5,000회 (t > 1.96, CI가 0 미포함)
4. **예측력** — Q² > 0 (Blindfolding), PLSpredict로 LM 대비 RMSE 비교

| R² — 표본 **내** 설명 | Q² — 표본 **밖** 예측 |
| --- | --- |
| 이 표본에서 종속변인 분산을 얼마나 설명했는가.<br><br>모형이 복잡할수록 자동으로 커집니다. | 새 관측치를 얼마나 잘 맞히는가.<br><br>0보다 커야 예측 적합성이 있습니다. |

### 2차 요인을 PLS에서 다루는 법

| 접근 | 방식 | 권장 |
| --- | --- | --- |
| 반복지표 | 하위요인 문항을 상위요인에도 그대로 투입 | 간단하나 편향 가능 |
| 2단계 (two-stage) | 1단계 잠재점수를 2단계 지표로 사용 | **현재 권장** |
| 혼합 | 형성적 상위 + 반영적 하위 | 이론에 따라 |

```r
mm <- constructs(
  reflective("SK", g("SC_SK")), reflective("SJ", g("SC_SJ")), ...,
  higher_composite("SC", c("SK","SJ","CH","IS","MI","OI"),
                   method = two_stage, weights = mode_A))
est <- estimate_pls(data = d, measurement_model = mm, structural_model = sm)
bt  <- bootstrap_model(est, nboot = 5000)
pp  <- predict_pls(est, technique = predict_DA, noFolds = 10)
```

## 다층분석 — 어느 층의 이야기인가

!!! abstract ""
    같은 조직 사람들의 응답은 서로 닮아 있습니다. 이 **비독립성**을 무시하면 표준오차가 과소추정되어 유의하지 않은 것이 유의해 보입니다.

### 다층모형 (HLM)

<div class="tri" markdown>

**1. 쉽게 말해** · 데이터에 층이 있습니다 — 개인 안의 팀, 팀 안의 본부. 팀 효과와 개인 효과를 섞지 않고 분리합니다.

**2. 논문·실무에선 이렇게 쓴다** · "조직 수준 분산이 전체의 14.4%를 차지하여(ICC = .144) 다층분석의 적용이 정당화되었다"

**3. 읽고 판단하는 법** · **ICC ≥ .05~.10**이면 다층 진입 근거가 됩니다. 이 값이 사실상 'HLM을 쓸 자격 증명'입니다.

</div>

### 일반 회귀의 세 가지 실패

1. **표준오차 과소추정** — 같은 팀 사람을 독립 관측치로 세어 N을 부풀립니다.
2. **생태학적 오류** — 조직 수준 관계를 개인 수준으로 잘못 해석합니다.
3. **이질성 무시** — 관계의 강도가 조직마다 다를 수 있다는 사실을 못 봅니다.

### 모형 구축 순서

| 단계 | 모형 | 확인 지표 |
| --- | --- | --- |
| 1 | 무조건모형 (Null) | ICC · τ₀₀ |
| 2 | 무선계수모형 (L1 변인 투입) | γ₁₀ · **τ₁₁** (기울기 분산) |
| 3 | 절편모형 (L2 변인 투입) | γ₀₁ — 조직 변인이 평균을 바꾸는가 |
| 4 | 절편·기울기모형 | **γ₁₁** — 조직 변인이 개인 관계를 바꾸는가 |

### 중심화 — γ의 의미가 완전히 달라집니다

| 방식 | 계산 | 해석 |
| --- | --- | --- |
| 집단평균중심화 (CWC) | X − 집단평균 | 순수 개인 내 효과. 조직 효과 완전 제거 |
| 전체평균중심화 (CGM) | X − 전체평균 | 개인 내 + 집단 간 효과 혼합 |
| 무중심화 | 원점수 | 절편 해석이 무의미해지기 쉬움 |

!!! warning "REML과 ML을 섞지 말 것"
    **무선효과** 비교는 REML, **고정효과** 비교는 ML입니다. 이것을 섞으면 우도비 검정이 무의미해집니다.

### 개인 응답을 조직 변인으로 올릴 때

'학습지원문화'처럼 개인이 응답한 것을 조직 평균으로 합산하려면 합의도 증명이 필요합니다: **r_wg ≥ .70**, **ICC(1) 유의**, **ICC(2) ≥ .70**.

```r
m0 <- lmer(TI_TOT ~ 1 + (1 | org_id), data = d, REML = TRUE)
performance::icc(m0)

multilevel::rwg(d$LS_TOT, d$org_id, ranvar = 2)$rwg |> mean()
multilevel::ICC2(aov(LS_TOT ~ factor(org_id), data = d))

m3 <- lmer(TI_TOT ~ SC_cwc + WE_cwc + LS_gmc + SC_cwc:LS_gmc +
             (1 + SC_cwc | org_id), data = d, REML = FALSE)
summary(m3)   # γ₁₁ = 교차수준 상호작용
```

### M6의 수수께끼 풀기

M6 실습에서 `SC × LS` 상호작용이 개인 수준에서는 유의하지 않았습니다. HLM으로 올라가면 **조직 수준**에서 유의한 교차수준 상호작용(γ₁₁)이 나타납니다. 같은 변인이라도 **어느 층에서 작동하는가**가 다르다는 것을 보여주는 사례입니다.

!!! note "해석 연습"
    γ₁₁이 유의할 때 이렇게 씁니다: "학습지원문화가 높은 조직에서는 자기자비가 이직의도를 낮추는 효과가 더 강하게 나타났다(γ₁₁ = −.71, p = .009). 단순기울기 분석 결과, 학습지원문화 +1SD 조직에서는 β = −.68(p < .001)이었으나 −1SD 조직에서는 β = −.19(p = .21)로 유의하지 않았다."
